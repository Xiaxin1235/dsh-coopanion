# O03 手型资源

`reach.png`、`grip.png`、`release.png` 是内置 image_gen 根据原角色 `arm_far_end_front.png` 编辑生成的三种透明手型，分别制作了伸手、握持和放松的候选轮廓。三张均保留 1254×1254 RGBA 原字节，没有裁切、改色、抠图或缩小重写。

`asset.json` 保存原图摘要、画布／可见范围、源像素腕点／抓握点、模型锚点、抓握壳缘位置和提示词全文。制作与实际画面验证见 [工作记录](../../../../docs/design/art-workflow/o03-shell-hands-v1/README.md)。

当前渲染使用 `grip.png` 作为唯一动作母版：固定袖口／手掌，以 24×32 网格连续展开和收拢手指。姿势权重只驱动形变，手部表面的透明度保持 1；`reach.png` 和 `release.png` 保留作候选对照，不再参与逐帧换图。`hand-art.js` 中的源像素多边形把掌部与前景指尖分成互补表面，每个源像素只进入一个表面；运行时生成纹理，没有改写磁盘上的 PNG。

工作台在同一帧按手掌／身体、贝壳、指尖合成，地面与手中拥有权共用物件绘制层。两层手部图像解码完成后再一次性提交画面；细节放大直接使用同一合成结果。`asset.json` 中原有 `frontRect` 是上一轮裁切方案的制作标定，当前分层使用 `handSurfaceModel()` 的多边形。

新手型是基于原角色素材的衍生编辑，原角色与上游素材署名见 [第三方说明](../../../../THIRD_PARTY_NOTICES.md)。本资源没有改变原角色贴图或其署名信息。
