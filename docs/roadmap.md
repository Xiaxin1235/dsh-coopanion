# 桌面伙伴路线图

更新：2026-10-15。当前交付和验收状态见[文档索引](README.md)。M1–M6 已纳入 v0.4.9；实施时的计划、参考快照、进入条件和阶段结论保留在[历史路线图](archive/2026-10-m1-m6/roadmap.md)。

## 产品范围

- 保留 Coopanion API 2 的实时网格、表情、视线、说话脉冲、物理互动和角色包沙箱，按角色实际词表调用动作。
- 用户明确选择 Harness 普通会话，沿用其模型、工具和权限；后台任务保持关注会话与阅读稳定。
- 完整回复、按会话合并的未读、继续交流和待办入口协同工作；查看、已读与实际审批／答复分别结算。
- 本地互动与闲时节奏服务角色陪伴；新能力先有可验证的问题，再确定接口和边界。

Computer Use、额外 Agent 调度、自动审批、本地模型／OCR、天气新闻、定时模型闲聊、余额查询、多宠同屏及独立运行需要新的明确需求。当前角色运行时、鉴权和沙箱继续作为基础。

## 后续候选

以下仅为候选，启动前按用户需求确定单项范围、接口和退出条件。

| 候选 | 进入条件与可验证结果 |
|---|---|
| 桌宠内简单提问直答 | 两版公开答复接口、完整请求身份、取消与断线交还语义先验证；审批仍由正式流程处理 |
| 阅读增强 | 有实际阅读问题后补充复制、代码高亮或公式；保留清洗、已读身份和捕获正文 |
| 角色制作体验 | 沿 `examples/star`、`character:pack` 和已有预览完善教程与视觉检查，继续使用 API 2 |
| 版本与资源反馈 | 有明确需求后显示运行／安装版本与重启提示；电源或降帧策略先固定基线、预算和作用范围 |

## 验证与交付

跨模块变更先固定共享契约，再接入 Host、Client 与桌面；每项变更形成可审阅差异和对应验证。类型、单元、浏览器、原生及两版正式安装按影响范围执行，矩阵以 CI 配置为准。物理多屏、通知中心、真实模型和长期资源检查记录实际环境与限制。

新增记录绑定完整源码提交、宿主版本和实际包摘要；版本修改与对外发布按[发布流程](releasing.md)单独处理。
