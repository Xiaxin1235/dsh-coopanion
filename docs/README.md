## 历史资料与本机输出

[归档目录](archive/README.md)保留已经执行的计划与阶段交接；[证据目录](evidence/README.md)保留固定提交的验收材料。它们提供来源与复现信息，不安排当前任务。原始证据路径和字节保持不变，以保留摘要链。

`.cache/` 保存工具链、旧 checkout、固定测试包及下载证据；`artifacts/` 保存本机测试输出，可能来自不同提交。两者已被 Git 忽略，普通 `rg` 也跳过归档与证据。追溯时显式使用 `rg --no-ignore` 并核对完整身份；新检查用独立目录，避免覆盖历史包或把旧截图当作本次结果。当前目录中的缓存是否仍存在不属于证据有效性的保证。

更新行为时同步对应契约；更新交付或验收状态时修改本页并链接新增证据。发布说明保留各版本原意，历史记录中的过期状态在本页解释，不回写为后来的结果。
