- 增加默认关闭的本地诊断开关和只读接口，通过本机 socket／命名管道提供有限状态与计数，不记录聊天正文或互动身份，不开启 Chromium 调试端口。
- 随包提供独立采样器，支持进程重启分段、采样中断记录、限量本地日志和报告导出；采样器不驱动桌面输入。新增独立锁屏／休眠状态和事件计数，以及带时区的日历截止 `--until`；休眠缺口分段记录，不补记为有效活动。

自主陪伴与诊断均为默认关闭的 P1 试用功能。P1 长时资源、短时自然体验及平台验收分别记录，用户已取消七天／填表要求，不以安装成功替代验收。支持宿主版本仍为 0.2.0-rc.2 / 0.2.1-alpha.1。

安装包：`dsh-coopanion-0.4.10.tgz`；npm 与 GitHub Release 的版本化包、固定别名使用同一份发布 CI 验证的压缩包。

# v0.4.9

## 任务、会话与桌面陪伴

- 区分“本轮回复已生成”和目标真正完成：只有正式提交的目标完成才庆祝，目标中间轮保留全文和未读；继续、暂停、阻塞、错误与停止分别呈现，历史恢复不重放提醒。
- 桌宠输入可直接续接明确选中的普通会话，包括尚未打开的历史会话。通过 Harness 正式 Session Controller 排队提交，保持请求身份、持久去重与串行准入；接受回执只表示已进入队列，结果仍由原会话产生。
- 桌宠意外退出后按 1、3、10 秒间隔最多自动恢复三次，稳定运行 60 秒后清零；恢复保留隐藏状态、关注会话、完整结果、未读和有效待办，不重发聊天。设置页显示恢复状态并提供重启。进程退出时，窗口内临时草稿和阅读位置仍会丢失。
- 新增独立文字大小 100% / 125% / 150%，气泡、聊天、收件箱和菜单同步生效；调整字号保留当前阅读、草稿及在途发送，角色尺寸单独控制。
- 拖拽松手可切换到原生鼠标所在显示器，托盘可选择“移到显示器”；当前屏断开后回到有效工作区。几何更新保留当前窗口的阅读与草稿，并修正拔屏期间的拖拽结束、动作顺序和命中区域。
- 新增默认关闭的“日常陪伴节奏”，需同时开启闲时走动。按系统本地时间，07:00–22:00 每 45–90 秒尝试现有轻动作，夜间每 2–4 分钟仅轻点头或坐下；任务、待办、阅读、输入、拖拽、休息和减少动态效果优先。偏好即时保存，不增加模型请求或通知。

支持 DSH 0.2.0-rc.2 / 0.2.1-alpha.1。M1–M6 的本地验收、固定测试包与源码身份保留在 `docs/evidence/`；这些历史测试包的版本为 0.4.8，不能作为本版本分发包的校验值。发布 CI 对 v0.4.9 另行执行三平台测试及两版宿主的六组同包安装检查。

物理多屏 / 混合 DPI、长期使用与资源表现、真实模型会话及物理系统通知中心送达仍待独立实机验收；受控测试与本机有限时长资源对照不替代这些验收。

安装包：`dsh-coopanion-0.4.9.tgz`。npm、版本化 Release 包及固定别名 `dsh-coopanion.tgz` 将使用同一次发布 CI 验证的压缩包。

# v0.4.7

## 未读回复按会话去重

- 同一会话的多个未读回合合并展示最新回复，信封、收件箱、会话列表及托盘的未读数量按会话计算。仅有一个未读会话且没有其他待办时，一次点击直接打开最新全文。
- 主动阅读、关闭回复气泡或通过回复继续对话时，确认展示时包含的未读回合，避免旧回复再次进入收件箱。阅读期间新完成的回合继续保留未读，不替换当前内容；完整历史结果仍保留。

- 全文支持标题、粗体、列表、引用、表格、链接及代码块，表格和长代码可横向滚动，窄屏阅读面板保持在窗口内。
- 原始 HTML 作为文字显示，过滤可执行链接，图片保留替代文字。渲染资源随安装包分发，回复原文继续保留。

新增同会话多回合、已读确认与新回复到达、单会话一键阅读、Markdown 格式、安全渲染及窄屏浏览器回归；原生 IPC 回归覆盖合并回复的完整身份和粗体渲染。

# v0.4.6

## 修复历史会话与重启状态

- 打开历史会话时，旧的最终回复作为已读基线保留，不再全部进入未读列表。只有当前 Harness 运行中实时完成的新回复增加未读；同一 Host 内已有的未读和阅读状态继续保留。
- 恢复会话时核对当前 Agent 是否实际运行，空闲或没有 Agent 的历史未结束回合不再误触发思考、输出或工具动画。仍有效的审批和提问保留待处理入口。

## 更直接的回复收件箱

- 信封与托盘的“待查看”入口统一展示回复、审批、提问及异常。仅有一份未读回复且没有其他待办时，一次点击直接打开全文；多份回复显示摘要，各自提供“继续对话”直达源会话。
- 阅读后台回复不切换正在聊天的会话。收件箱阅读器支持跨会话连续阅读和返回收件箱；新结果不替换当前内容，也不改变已打开的阅读顺序。
- 列表摘要与收起收件箱不标记已读，主动阅读全文或通过该回复继续对话才确认对应结果。打开源会话不代替审批或答复，稍后提醒仍由 Host 确认。
- 沿用角色气泡的描边、尾巴、配色及定位；修复窗口尺寸变化后气泡与桌宠脱离的问题。保留阅读、输入和拖拽保护，补充键盘操作、双语及窄屏检查。

新增收件箱浏览器及历史恢复回归，并覆盖真实原生 IPC 的单份后台回复入口与准确会话跳转。发布 CI 包含 Linux、macOS、Windows 与 DSH 0.2.0-rc.2／0.2.1-alpha.1 的六组安装检查。

安装包：`dsh-coopanion-0.4.6.tgz`。npm、版本化 Release 包及固定别名 `dsh-coopanion.tgz` 使用同一份通过 CI 的压缩包。此节作为 GitHub Release 正文供 dshmarket 的修改记录抓取；市场收录及目录刷新由社区目录处理。

# v0.4.0

动画和角色系统改为直接复用 Coopanion 的 AGPL 运行时。大肥鱼恢复原生网格变形、弹簧动作、动态五官、拖拽 / 抛掷物理和八套配色；说话使用描边气泡、逐字显示、嘴部动作和合成音效。

角色包统一为 `figure.json` API 2 ZIP，支持动作预览、配色 / 多轴换装、角色切换和重启保存。旧 `.dshpet` v1、Canvas 关键帧引擎、旧 schema 和转换工具全部移除。此版本为破坏式更新，旧角色选择重置，需重新制作或导入 API 2 包。

Harness 会话、聊天、审批提醒、原生设置和透明置顶窗口继续保留。角色脚本在无网络的 opaque-origin iframe 中运行，不开放 Node 或 Electron 桥。

移除角色旁常驻的会话气泡、悬浮按钮、状态装饰和底部名称标签。双击角色打开聊天，再点击当前会话切换对话；右键角色打开菜单。

展开的菜单和面板保持位置稳定，避免随角色呼吸移动；说话气泡继续跟随角色。动画调度限制待处理帧，避免慢速渲染时积压输入。

组合程序改为 AGPL-3.0-or-later；保留原 MIT 署名及上游素材的独立权利声明。菜单可下载当前程序的完整对应源码。

支持 DSH 0.2.0-rc.2 与 0.2.1-alpha.1；请使用生成的 `dsh-coopanion-0.4.0.tgz` 安装。此工作不自动发布 GitHub Release 或 npm。
