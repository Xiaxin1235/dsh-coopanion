## 交付行为

内置鲸鱼在已许可、键盘空闲的小景中自主关注对象，再实际走近、拿起贝壳、整理到小窝附近；已整理完成后本次运行不反复搬动。工作或手动活动来时保留生活目标，实际落物、收手后让出同一身体；解除后核对当前对象并恢复原目标。观察与清醒休息继续沿同一帧时钟进行。行为容量、失败与热切规则见[装配契约](../design/living-integration-contract.md)。

`living-body.js` 从原工作台提取，工作台重导出同一工厂。默认身体、手部与持物在同一渲染帧合成，主页面不搬运逐帧 PNG。正式 Host 的 WorkSources 通过既有快照发送无正文元数据，源 epoch／修订和旧 Agent 闭包隔离迟到事实；目标完成继续使用共享完成判断。运行时问题、continued、审批与异常不会被普通回复或查看动作随意清除。

安静／活泼在主页面和 Settings 可切。最新确认的 pet/play 类别影响对象偏好和整理前等待；自动观察、整理、休息只留下运行期进度，不写相处记忆或关系分数。5B 的明确回应、实际保存确认和记忆撤销，5C 的即时反应和有限合批继续保留。关闭小景、自定义角色和小视口按能力回退。

## 发现与修复

- 默认工厂与工作台分离：共享工厂提取至 `web/`，不依赖正式安装包之外的 `docs/` 和生成工作事实模块。
- 释放编排姿态后 gripFrame 缺少 sit 等实测数据，使到岗准备超时；先复现单元失败，再改为独立提供真实站立测量，浏览器／原生工作停车和恢复通过。
- 拾取朝向被“看向背后鼠标”改变，产生接触超时；单位与真实页面先复现失败，接触及暂停的动作拥有朝向，保留原 1.5px 门槛，修复后实际拾取通过。
- 共享适配器遗漏 `drop`／`shift`，原拖放和多屏回归发现后补齐；90／240px 的比例与视口变化由真实页面补验，240px 底部安全边距按实际可用空间修正。
- 从未启用小景时，显式互动误入生活交接；仅实际启用过的小景参与退出交接，非小景的互动不请求该身体所有权。协调器只清除自己退出的关注手势，保留手动活动的波手／舞蹈。
- 兼容测试分别等待实际存档请求和两次已送达的抚摸动作，再断言延迟存档与“不重播”；新纯元数据设置消息不计作重播动作。临时调试输出已移除，失败日志与最终结果分开保存。

既有原生重启命中的历史间歇性超时不宣称根因已修复。此次工程通过不表示物理多屏／混合 DPI、物理键盘跨应用、真实模型、三平台 CI、长期资源或用户观感验收。
