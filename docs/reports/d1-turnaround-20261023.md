# D1 统一静态转面候选与原位拼合

固定实现 `57fd025`；在提交后干净源码上验证。当前交付与接受状态看[开发入口](../aliveness-development.md)，制作规格见[工作流复核](../design/d1-workflow-review.md)。

本轮将角色设计与动画接入分开，交付 R01 的单张四方向候选及审阅页；同时实现 R04 中真正关闭动画和静态补偿的原位拼合模式。未替换默认产品美术。

| 项目 | 结果 |
|---|---|
| R01 静态转面 | 内置 image_gen 生成 v1、局部编辑 v2／v3；三张原图、完整提示词与摘要全部保留。v1／v2 尾根卷钩未去除，记录为失败候选；v3 供审阅，母版未锁定 |
| 视觉复核 | v3 观察到斜后卷钩去除、背面及斜后无脸部；编辑同时改变白缎带边形与背面局部轮廓，不能声称其他区域像素不变。角色身份与原设计比例待用户复核 |
| R04 原位拼合 | 无动画模式清空变形状态，并令眼睛／视线保持中性；保留当前部件位置、五官校准和层级。时间归零与无动画两种入口明确区分。局部网格与连接点诊断尚未完成 |
| 浏览器验证 | 制作台 11 组通过；新模式先在旧实现上因动画输入改变画面而失败，再在修正后通过。静态转面页 5 组通过，覆盖来源摘要、图片切换、辅助线、尾根放大及页面链接 |
| 产品边界 | `export-direction-art.mjs --check` 通过，现有产品资源保持不变。没有新增运行时行为；未执行本轮 VM 原生、三平台或物理实机验收 |

[转面工作台](../design/art-workflow/d1-turnaround-v1/README.md)提供当前候选和原参考。[原始证据](../evidence/2026-10-23-d1-turnaround/README.md)绑定提交、源码摘要、浏览器版本与截图。
