# 2026-10-21：一起活动与记忆可感知闭环

基线 `c6caa57d5bcfb757c991150566dd61ad4da82854`，分支 `codex/aliveness-foundation`。用户反馈记忆的来源和作用难以感知、一起活动缺少互动感、头顶状态横条与人物不协调。本轮作为 5B 反馈修正实施、验证和本地提交，不启动 5C 队列或后续阶段，不推送、合并或发布。

## 实现

原活动点击后自动播完即结算，用户不必再参与。现在角色先招手，近身短便笺等待用户点击／键盘激活“回应她”；收到回应后才执行有限开心动作并完成。等候最多 20 秒，无回应、稍后／Escape、工作／阅读／拖动、关闭陪伴等取消不写活动记忆、不计关系。重复回应不会重启活动或延期。缺词仍使用已有能力降级，不增加素材、模型或系统通知。

抚摸与活动先表达开心，只有存档回执包含本次事件 id 才显示“记住了”；写失败明确说明没有保存。回执绑定角色和反馈代次，并检查界面占用与原反馈是否已被收起，避免晚回执重显。下一次主动一起活动按最近有效条目的类型／纠正类型提起上次一起玩或摸摸；没有记录不编造经历。既有低频邀请的点头、关系计分与容量／撤销契约保持，原有记录不伪装成新版回应经历。

头顶长条来自短反馈复用长回复的固定宽度与外层滚动。等待、邀请、存档／抚摸反馈现有独立近身便笺规则：随内容宽度、最多 252px × 字号、16px 圆角、轻投影、外层不滚动，继承角色纸面和动作色。等待视图可回应或安静退出，不抢焦点、不进入工作收件箱。
