# 第 5A 期：五项观感反馈修正（2026-10-20）

用户指出首版 `e4858dd` 的五项问题：过多坐下、人格差异只在时间上、坐站不自然、动作／表情库利用不足、随机移动不等于探索。本轮按这些反馈修正；首版工程记录保留为[固定快照](stage-5a-20261020.md)，不能解释为观感验收。修正后的主观自然度仍待用户确认。

## 已改变的行为

| 反馈 | 本轮实现与验证信号 |
|---|---|
| 太喜欢坐下 | 普通关注及抵达不再自动 sit；工作只有同一模型／工具等待稳定 35 秒才坐下，真实新活动／工具进展才重新起身，不再固定 12 秒坐站轮换 |
| 人格只改变时间 | 安静偏贝壳／小窝、远看细察；活泼偏花箱／新对象、侧向接近查看。同种子且两组时间与移动概率完全相同时，仍选择不同对象、站位和实际表情 |
| 坐站不自然 | 先复现坐姿 yield 误入物件 retract、腰部弯到 20°；改为独立 standUp，等待实际 sit 权重归零。原生轨迹检查不再经过该弯腰 |
| 没结合现有词表 | 释放空闲腰／手臂覆盖，复用 thinking／surprised／happy、实际转向、点头与身体呼吸；从实际 rig 读取表情、手势与眼部锚点，不用策略标签冒充渲染结果 |
| 随机移动不是探索 | 删除匿名邻近点，使用已知贝壳、花箱、小窝的身份、实际位置、观察站位与注视点。到达后仍须转向、视线收敛并有有效观察，刚看过的不立即重复。对象移动时旧意图失效并现场重评 |

空场景不会生成替代随机路线；运行期最多 8 个对象、16 条解释记录，90 秒有效活动内避免同位置重复。标记不写存档、不计成长。无模型调用、外部应用／屏幕／键盘内容读取，也没有装配默认产品二维人格或扩展 5B／5C。

另外复现并修正了参数编辑旧帧回写：旧角色帧不能覆盖未提交输入；“应用”捕获并约束实际输入。确定性控件测试及原生／浏览器的同参数对照都检查这一点。

| 人格 | 目标与真实站位 | 实际 rig 表情／关注 |
|---|---|---|
| 安静 | 贝壳，`(195,555)` | thinking，向下细看贝壳 |
| 活泼 | 花箱侧前方，`(381,385)` | surprised，向花箱查看不同局部；有效观察后 happy 与一次 nod |

花箱站位经画面检查改为侧前方，保留花箱可见性；不把角色遮住对象的“抵达”当作可见交付。真实转向、眼部投影锚点和视线收敛参与观察门槛，时间／表情本身不结算观察。
