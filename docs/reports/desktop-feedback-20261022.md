最终源码、逐文件 SHA-256、构建标识与本地包摘要见[验证清单](../../artifacts/living-feedback-20261022/validation.json)。测试在工作树运行，提交后核对相同源码字节；包只作本地核验，未安装日用 Host、推送、合并或发布。

## 复现、原因与修正

1. 主页面将根位置不动的拿放误判为空闲，触发 30fps 限制。真实页面 2.4 秒中有 144 次显示回调，身体只收到 52 帧；同一测量修正后为 144／144，新循环页面复测为 143／144。原生最终测量另列于验证清单。现在接触、抬放、姿态过渡和视线对齐属于活动，完全空闲仍保留绘制上限。该比例证明主动限帧已解除，不替代所有设备的长期 GPU／资源验收。
2. 暂停的空手 idle 被 yield 当作抓取中断，进入 retract。最小单元先失败再通过；现在直接释放中性暂停，不播物件收手。真正伸手／握持中断仍保留姿态和真实拥有权；用户输入往返的真实页面补验没有 reach／grasp／retract，也未新增拿放提交。
3. 旧策略完成一次整理后缺少后续目的。默认现在按具名桌面空间用途组织“观察并整理 → 外出观察活动边界 → 返回停靠 → 清醒休息 → 再次外出”，每次访问具有 token／几何修订，实际到达和有效观察共同推进，不能靠计时证明访问。工作／互动／输入保留原目标。
4. 撤下默认常驻小屋和珊瑚，保留原制作资源。默认只剩身体、有限活动范围、停靠点和一枚小贝壳，不对隐藏家具假装观察。
5. 键盘活动／鼠标接近先安全交接，再在附近留意实际鼠标或输入；8 秒连续键盘 idle、鼠标离开至少 1.2 秒后重评。unknown 保守暂停。可信系统恢复最多一次有限提示，15 秒后不补播旧事件。没有新增屏幕、按键正文或其他应用内容读取，也没有模型心跳。

新流程首次装配还暴露“中性执行器已暂停、协调器仍试图准入访问”的接口状态；实际页面复现后增加中性状态释放回归，避免误报 action-paused。修正仍在同一协调器与帧时钟内，不另加调度器。
