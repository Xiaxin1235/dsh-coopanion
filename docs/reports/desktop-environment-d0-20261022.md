## 实现与验证

新增统一的 `collectWindows` 探针 Interface，分别通过 CoreGraphics、DWM 和 X11／EWMH 读取测试进程窗口。调用有时间、输出与容量上限；拒绝错误所属进程、重复身份、非法几何和错误单位。成功空快照、partial、unsupported、采集失败分别记录。平台坐标在探针消费层经 Electron 转为全局 DIP，未改变默认产品身体、导航、输入或工作完成语义。

`npm run probe:desktop-environment` 使用临时 profile 和测试拥有的两个无边框窗口，原生采集与测试窗口控制相互独立，不注入窗口列表或预期坐标。每步同时记录 OS 采集和测试窗口实际参考几何。报告不输出其他应用的身份、标题、内容或截图。

macOS 原生首轮在受限执行沙箱中 SIGABRT，另一次发现 CFArray 桥接未展开导致空枚举；修正后用同一真实窗口断言通过，并加入实际 JXA 桥接回归。完整回归的首轮资源采样受执行沙箱禁止 `ps` 影响；允许本机进程读取后完整通过，未降低断言。原始失败记录保留其原身份，不是最终源码的失败结论。

## 保留缺口

D0 尚未完成：需要 Windows、真实 X11 桌面与相应 CI 结果；无边框测试不证明装饰边框、第三方应用窗口、透明覆盖层、穿透、全屏／Space／工作区、权限撤销、多屏混合 DPI、物理输入或锁屏恢复。Wayland 的产品能力与合成器路线仍待探针和明确决策。采样 TTL、资源预算及正式分发依赖尚未冻结。

当前工具不接入产品运行时，不构成 D1 平面身体或 D3 窗口附着交付；基础产品行为保持原契约。浏览器／NPC 源码未变，本轮未重跑 `test:inbox-ui` 或安装矩阵，也没有日用安装、推送或发布。
