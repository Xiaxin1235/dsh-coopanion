# 长暂停后的首次继续

`before.json` 使用真实页面按钮：grasp 中暂停，等1.3秒，点击一次继续，再等0.8秒，仍为 paused，动作时钟不动。`after.json` 相同操作已进入 lift，没有重置操作代次或物件身份。

原制作工厂只在未暂停时调用 `stepMotion`，所以暂停时虽然宿主帧继续发来，状态的 `lastAt` 未刷新；一次显式 resume 被旧时间缺口保护吞掉，首次点击只刷新安全时钟。修复是在暂停帧以 dt=0 继续更新安全心跳，保持姿势／动作时间／拥有权冻结。真实长间隔保护仍在，未改公共动作策略或产品默认工厂。

回归加入 `tests/space-preview-ui.mjs`：暂停1.3秒核对冻结，单帧推进，再暂停1.3秒后只点击一次继续，要求实际拿放完成。旧44项及像素门槛也重新运行。
