# O03 贝壳：美术工作流试跑

状态：正在制作的资源样板，非正式运行资产。对应[资源表 O03](../../aliveness-art-assets.md)。

目标：用一个小道具跑通需求、生成、透明度／边界检查、锚点标注和实际尺寸预览。原角色仅作比例与风格参照；本次不制作新角色或宣称二维身体、真实拿物已实现。

## 需求

- 一件贝壳，扇形、圆润、轮廓清楚，适合大肥鱼整理／拿放。
- 深蓝轮廓、浅奶白和淡粉，与现有角色的干净动漫线条及柔和配色协调。
- 单件、透明背景、无文字、无地面／阴影，便于独立放置。
- 在 24／40／64 CSS px 宽度及浅／深背景检查可读性。
- 完整原图与提示词保留；不以抠图、改色、裁切掩盖生成失败。
- 底部接地点、抓握点由人工观察及透明边界推定，标为候选锚点，不冒充真实角色接触验证。

## 执行阶段

1. 固定需求与生成提示词。
2. 使用内置 image_gen 生成透明候选，保存工具返回的原始文件。
3. 检查真实 alpha、非透明包围盒、留白、连通性和文件摘要。
4. 在本地预览中以实际尺寸显示，测试底色与候选锚点；需要改图时继续用 image_gen，保留新版本。
5. 记录可见效果、通过项与仍需角色接触验证的限制。

生成来源使用内置工具，不要求 API key，不引入远程运行时资源。原始生成结果不是 PSD 分层源稿；不得声明完成分层绑定或正式许可审查。
