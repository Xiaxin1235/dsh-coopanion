### 统一尾巴构造

- 角色原型为蓝鲸：粗实尾柄连接左右展开、中央有缺刻的两个尾鳍，避免鱼尾式上下两叶、额外卷钩或第三个鳍。尾背为低饱和蓝，腹面为浅灰白。
- 解剖连接点固定在后骨盆中线，被衣服覆盖；**可见尾柄只能从后裙摆下缘伸出**。正面由裙和腿遮住根部，侧面从后裙摆下伸出，斜后和正背也不允许从腰结下面跨在裙面上。
- 四视图使用同一个尾巴姿态和身体连接点，只改变投影、近远及遮挡。侧面允许尾鳍缩短／部分重合，不能为了展示两叶而把鲸尾旋转成竖直鱼尾。
- 腰结属于服装，不能当作尾根。头发遮脸不能通过缩小或更换头部轮廓实现。

旧约束“尾柄在裙子前、腰结缎带后”及“单侧蓝金头结”已被本次设计修订替代。旧绑定 `z=8` 探针仅复现旧稿错误，不是新稿层级规范。

候选图必须先核对四方向身份，再进入 R02 保留原画坐标的拆层。生成图是可见审阅候选，不是保真拆件或可编辑 PSD；文件创建、透明检查和预览可用均不代表用户已接受母版。

原图、完整提示词、引用摘要与候选评语保存在本目录 `source/`。沿用原角色与第三方权利声明，见[第三方说明](../../../../THIRD_PARTY_NOTICES.md)。
