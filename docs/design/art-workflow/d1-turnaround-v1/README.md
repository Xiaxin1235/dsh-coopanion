本轮先制作同一角色的静态转面，不拆件、不导出到产品。最新状态以[开发入口](../../../aliveness-development.md)为准，制作顺序见[工作流复核](../../d1-workflow-review.md)。

## 参考优先级与固定约束

1. `../d1-directions-v1/source/design-front-20261023.png`：用户提供的正面设计，主比例／脸型／发型／衣装基准。
2. `../d1-directions-v1/source/reference.png`：既有斜前模型的身份与方向参考；不将其单独比例覆盖正面设计。
3. `../d1-directions-v1/source/design-back-right-20261023.png`：斜后构造参考，保留用户要求的遮脸、去尾根回钩修订。

蓝金头结固定在角色自身右侧，不能按画面左右随意镜像。尾根在后腰结下的身体中线；斜后／背面的尾柄在裙子前、腰结缎带后，尾端只有两个尾鳍。头发遮脸不能通过缩小或更换头部轮廓实现。

候选图必须先核对四方向身份，再进入 R02 保留原画坐标的拆层。生成图是可见审阅候选，不是保真拆件或可编辑 PSD；文件创建、透明检查和预览可用均不代表用户已接受母版。

原图、完整提示词、引用摘要与候选评语保存在本目录 `source/`。沿用原角色与第三方权利声明，见[第三方说明](../../../../THIRD_PARTY_NOTICES.md)。

## 当前审阅与复现

打开[静态对照页](http://127.0.0.1:4189/docs/design/art-workflow/d1-turnaround-v1/index.html)。使用既有 loopback 制作服务，不重启其他制作页面。

- v1：四方向首稿，斜后尾根仍有青色卷钩，未通过。
- v2：局部编辑仍保留卷钩，且其他区域也有变化，未通过。
- v3：观察到斜后卷钩已去除、背面与斜后不露脸；作为当前审阅候选。白缎带边形和正背局部轮廓也受编辑影响，不声称局部编辑逐像素保留其他区域。四方向身份和正面脸型／比例仍待用户复核。

`source/manifest.json` 记录原图、提示词、引用摘要、候选状态、只读透明检查及复核标记。`reviewCandidate` 仅选择工作台展示图，`lockedMaster` 仍为空，`productExportAllowed` 为 false。当前没有新的分层或关节绑定。

原位静态拼合使用[旧拆件工作台](../d1-directions-v1/index.html)的“绘制模式”选择器；它用于暴露原素材与绑定偏差，不把新总图伪装成可以运动的分层模型。其回归命令为 `node tests/direction-art-ui.mjs`。
