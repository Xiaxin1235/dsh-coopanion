# 生活感设计与制作

接手先读[当前开发状态](../aliveness-development.md)，再按改动读取本目录契约。平面位置、拖放与身体朝向的缺口及可见验收条件见空间与身体复核；专项路线与三平台能力门槛见跨平台桌面互动方案。工程交付、用户观感与装配状态统一看开发入口，执行范围来自用户最新指令；蓝图和素材入口提供规划及查阅条件。

| 资料 | 查阅条件 |
|---|---|
| [空间与身体复核](space-body-review.md) | 接手生活感、调整空间／拖放／朝向或选择下一步前，先核对已知缺口与待实施目标 |
| [跨平台桌面互动方案](desktop-environment-plan.md) | 选择整体路线、建立环境 Module／Adapter、评估 Windows／macOS／X11／Wayland 或准备 D0–D4 工作包；实施路线与门槛，实际状态看开发入口 |
| [默认产品生活装配](living-integration-contract.md) | 平面放置、运行期停靠、跨区域返回、共享动作身体、正式工作事实与旧角色回退 |
| [回应与安静节奏](response-rhythm-contract.md) | 第 5C 期即时反应、有限合批、当前许可与过期撤销 |
| [消息视觉体系](message-visual-system.md) | 输出气泡、全文、滚动区域、色彩／轮廓／动作层级与人物协调 |
| [有限记忆契约](companion-memory-contract.md) | 第 5B 期可信互动记忆、容量／迁移、查看／纠正／删除与招呼 |
| [人格行为契约](personality-behavior-contract.md) | 第 5A 期安静／活泼参数、选择理由、许可与从实际姿态重评 |
| [双线协调契约](life-work-contract.md) | 第 4 期生活意图、工作事实、唯一身体拥有权、交接与恢复 |
| [连续动作契约](continuous-action-contract.md) | 第 3 期姿态衔接、独立物件、持物导航或中断恢复 |
| [生活空间契约](living-space-contract.md) | 修改制作工作台坐标、地面／立面、禁区、规划、拖动或遮挡；产品差异见装配契约 |
| [空间预览](art-workflow/space-v1/README.md) | 操作同地图、复现花箱反馈或运行定向回归 |
| [O03 工作台](art-workflow/o03-shell-hands-v1/README.md) | 调整连续手部、接触或同帧物件合成 |
| [方向制作工作流复核](d1-workflow-review.md) | 用户再次指出身份漂移／斜后尾巴错位后，接手 D1 美术与绑定前先读；包含失败复现、流程纠正与验收顺序 |
| [统一静态转面候选](art-workflow/d1-turnaround-v1/README.md) | R01 四方向总图、参考优先级、候选来源与审阅；当前 v3 未锁定，不可作为已验收拆件 |
| [D1 方向资源表](d1-direction-assets.md)与[制作样片](art-workflow/d1-directions-v1/README.md) | 资源规格、生产接入门槛与独立制作操作；状态见开发入口 |
| [制作工作流](art-workflow/README.md) | 已有运行画面证明需要补素材或动作 |
| [后续蓝图](aliveness-implementation-plan.md) | 规划或选择下一阶段；第 7 节维护上游人格／记忆／互动节奏的复用与自研边界 |
| [素材入口](aliveness-art-assets.md) | 按具体缺口复用资源；完整旧需求池仅供归档追溯 |
