# 生活／工作双线：第 4 期制作预览契约

状态：本地可运行切片已实现；工程结果见[开发状态](../aliveness-development.md)，用户观感尚未验收。显式 `?stage=4` 复用第 3 期地图、二维导航、连续动作与唯一帧时钟；`?stage=3` 和无参数第 2 期保持原行为。默认产品尚未接入二维物件故事。第 5A 期 `?stage=5a` 通过同一协调器加入可选人格日常，准入、参数及重评见[人格行为契约](personality-behavior-contract.md)。阶段授权与发布范围只看开发状态。

## 事实与准入

`src/work-facts.ts` 将受信调用者提供的公开已提交 SessionEvent 转成无正文工作事实，完成分类只使用 `src/completion.ts` 的 CompletionTracker。会话 seq／turn 与 Agent 附着 epoch 分别去重；模型帧的 revision 每帧递增，另按 attemptId／index 隔离。`WorkSources` 发行附着代次，替换／分离后的旧闭包不能更新新来源；恢复历史只建立静默基线。接受回执不释放工作，不产生完成。审批由原生 id 配对；限时问题适配接口接收公开投影的请求身份及独立修订结算，回合结束不能清掉 continued 问题。异常需显式确认，确认不结算审批／提问。

制作预览使用 `src/work-preview.ts` 中经过正式类型检查的隔离模拟事件生成器（审批每次独立 id、完整 outcome），清楚标为“模拟 Harness 事实”；页面不连接 Harness。事实适配另经四版本正式 profile loader 与受控模型验证，证据范围与页面模拟分别报告。浏览器模块由同一 TypeScript 源码构建，不能另写一份成功分类。预览构建只将已安装目标包中未使用的宿主服务初始化标为可消除，投影／严格折叠及完成判断保持原源码；构建拒绝残留宿主导入，测试对照宿主与生成模块。目标包导出结构变化时构建失败，需重新核对。生成模块不提交，先执行 `prepare-stage4.mjs`。

真实产品的 PetModel、NotificationBroker 已消费公开宿主事件；该适配器尚未装配到该产品通道。未来接入须使用受信宿主所有者，不能接纳角色 iframe 自报成功、工具输出或任意网页消息作为事实。

## 唯一身体入口

生活线保存贝壳对象身份、原落点和已提交进度；工作线按会话保留活动、结果与未决请求。`kit/life-work.js` 是唯一协调器，在同一个 body step 内发出动作或导航，不增加时钟、漫游或模型调用。工作事实立即更新关注／表情／说明，通知及逻辑处理不等待物理到岗。

首个故事由“开始整理”发起一次整理：拿起贝壳 → 工作到来 → 安全留物 → 到岗守候 → 真正完成 → 核对原目标 → 返回继续。普通回复只表示回合结束；目标推进保留目标信息，驻岗只由实际 running、未决请求或未确认异常决定；确认的新目标完成才呈现成功。实际到岗后按事实呈现准备、模型等待、思考活动、组织回复、准备工具参数、调用在途、请求失败与新尝试；审批与问题分别邀请许可和答复，continued 状态保留。守候有清醒坐姿、低频抬眼与原地起身，审批／问题优先站立；这些动作不证明工具执行进度。表情、视线和空闲手臂使用同一身体时钟，不改拿放接触通道。未决请求优先，其次异常、进行中的工作；同级保持当前关注，其结算后按本地接纳先后选择。源更新不改变会话展示顺序，不按名称或 delta 顺序轮换。一个会话完成不释放其他会话的需求，后台完成不覆盖审批／异常。结果与短反馈均有身份，重复事实、恢复与元数据更新不重播庆祝。

## 有界交接与真实进度

工作到来后先保留生活意图。未提交拿起的动作从实际姿态收手退出；手中物件在当前位置附近计算真实接触落点，经原接触／张手门槛落地，再收手起身。已经提交的放下只退出，不重新拿起。禁止将手中物件改写为地面或复位身体。手动路线也由同一交接入口取消，生活故事不能叠加到在途手动路线。交接最多 15 秒有效执行时间，失败保留拥有权并暂停，界面说明原因；提醒不因此延迟。准备／到岗同样有界，位置、速度和匹配的导航回执共同证明到岗，耗时不算到岗。

工作解除后重新核对当前贝壳身份、实际位置与原落点。原目标已达成则结束；仍有效则恢复原目标、从实际位置重规划；对象失效则结束并说明。本样板固定一个 O03 对象，不提供对象删除 UI；对象身份失效分支由纯策略测试验证。外部编辑落点表示用户更新生活目标；实体变化暂停后显式继续重规划。取消生活意图不删除实际物件或已提交进度，也不解除工作需求。

## 中断与兼容

用户拖动、Escape、页面隐藏、生命周期／长帧间隙优先：停止当前路线，冻结动作与协调进度，保留拥有权；显式继续后检查当前事实与几何。暂停期间仍接纳工作事实，不偷偷恢复运动。模拟会话选择／草稿与身体关注分别保存，后台事件不改写它们；聚焦草稿时冻结身体，离开后重新核对，不补播静默期间的短反馈。减少动态关闭视线／手臂节奏和周期站坐，必要的交接与请求姿态继续经原执行器。新导航使用新身份，旧代次／id／几何回执不能推进到岗；工作提前完成也必须安全退出当前交接再重评生活。

来源变为 unknown 时保留请求与会话信息并暂停身体，不把不可观测当作 idle，也不虚构正在运行；重新获得可信驱动事实后从实际姿态重评。输入占用解除不能覆盖拖动／生命周期等其他暂停原因。

第 4 期启用时手动拿放与行走只能在协调器待机且无工作需求时使用；故事执行期间都经协调器。编辑／显式重置、暂停与取消仍可操作。原有 off／roam、输入 unknown、隐私与无模型调用边界不变；本预览的显式开始不是启用产品自主陪伴。

## 验证结算

纯事实／策略测试覆盖完成、推进、普通回复、异常、审批、continued 问题、多会话、重复迟到、接受回执、取消、对象／目标变化、交接界限及过时回执。浏览器与临时 profile 的 Electron 执行真实导航和接触，包含拿放提交前后、拖动、几何及生命周期中断；完整 test:inbox-ui、既有导航／接触回归单独执行。源码摘要、构建模块摘要、运行时与输出目录绑定本轮状态。受控原生、物理设备、真实 Harness 和用户观感分别报告。

会话最多 32 个、每源问题投影最多保留 64 个请求／终态身份，审批最多 64 个，适配器修订与请求身份不截短；达到上限不驱逐未决关注：来源所有者明确拒绝新来源；请求或工具溢出发布 capacity 关注，不静默忽略。每源普通／嵌套在途工具最多 128 条。恢复基线、附着替换和旧回调隔离已在所有者中实现；默认产品二维故事装配仍是独立接入门槛。
