# 第 5A 期：人格、关注对象与表现

范围：显式 `?stage=5a` 的隔离制作预览，使用既有地图、180px 身体、40px O03、唯一生活／工作协调器与身体时钟。默认产品的后续装配见[生活装配契约](living-integration-contract.md)，复用本期人格而不把工作台参数编辑器搬入主页面。5B 存档、5C 回应合批、模型人格、出门与跨屏不在第 5A 期范围。进度与授权见[开发状态](../aliveness-development.md)。

## 人格配置与对象选择

当前策略为 `strategy:2`；显式配置仍兼容版本 1，不覆盖两组用户修改，不自动漂移人格。首版与反馈修正的差异、工程结果及待验边界见[阶段历史](../archive/2026-10-aliveness/stage-5a/README.md)。

关注对象仅来自已知小院的贝壳、花箱和小窝，每个对象有身份、当前位置、注视点和可达观察站位；内容禁区不成为兴趣对象。安静偏向贝壳与小窝、远处细看；活泼偏向植物与新对象、接近查看。目标按对象偏好、当前距离、路径可达性与近期观察状态计算，种子只参与有界选择。具备导航与起身能力时，先过滤不可达站位，再按人格偏好和路径成本选择对象；偏好对象受阻就改选可达对象，已在观察站位附近则原地关注。全部受阻或缺少规划模型时中性停留，不将不可达对象记为已观察；无对象不补匿名随机空地点。站位保留对象可见性。对同一对象，安静维持细看，活泼查看不同局部并有一次低幅度点头；即使时长和移动概率相同，目标、关注方式及实际表情仍有差异。

默认安静停留 18–26 秒、接近概率 0.20；活泼 6–10 秒、接近概率 0.85。用户可分别修改停留下界 6–40 秒（修改后上界为下界 + 8）和概率 0–0.95。这些参数只控制已许可选择，不定义人格的全部行为。种子为 0–4294967295 整数；相同位置、对象、事实、配置、种子及序号确定性对照。切换／回退保留覆盖、种子和序号；未知名称或版本回退安静 v1，“恢复本组参数”仅清除本组覆盖。参数只在当前页保留。

## 有目的的观察与真实进度

需要接近时，经同一二维导航器过滤并执行对象站位；只有身份／代次／几何匹配、实际根到达、速度归零才进入对齐。朝向使用真实转身，注视以实际 rig 投影的眼部锚点计算，经连续视线收敛后累计至少 2.5 秒有效观察。仅走到、耗时、表情或发出点头不算观察完成。对象身份／位置失效即停止旧意图，布局变化保留显式继续门槛。

最多保留 8 个运行期对象观察标记；刚观察过的同位置对象 90 秒有效活动内不重复安排往返。对象移动或有效时间到期可重新参与选择。标记不写存档、刷新即清空，不是 5B 相处记忆，也不计成长。解释记录最多 16 条，列出对象、替代候选、评分、实际起点／站位、关注方式、理由及是否实际观察。

## 坐站与动作库

普通观察保持站立，停留或抵达不自动坐下。坐姿退出使用专门 `standUp`，等待实际 sit 权重归零及停稳，不经过物件收手的 20° 弯腰。工作守候默认清醒站立；仅无请求／错误、同一模型或工具等待稳定至少 35 秒才坐下，持续同一等待不按固定周期反复起立。新工作活动或请求优先安全起身，不假报进度。

空闲观察与起立释放制作姿态对腰和手臂的覆盖，沿用既有 thinking／surprised／happy、转向、点头、视线与身体呼吸。表现取决于对象和实际进度，不随机播放全动作库。缺词退回 neutral／静默，缺二维能力或起身词原地观察；减少动态关闭可选接近、扫视和点头，不把中性静止记成对象观察。工作及接触拥有更高优先级，抢占清除未完成的可选短手势，表情不改变完成、审批或错误语义。

## 准入与中断

实验初始关闭、roam 未许可、输入 unknown。页面的 off／quiet／interactive、粗粒度输入、阅读／草稿／发送／今天安静均为明确标记的模拟许可，不是系统感知。off／roam 关闭约束可选日常；已开启实验中的输入非 idle 或占用冻结包括到岗在内的身体，同时继续接纳工作事实。quiet 不自动邀请，interactive 不扩大原预算；无新台词、邀请、模型调用或外部应用／屏幕／键盘内容读取。

切换、停止、回退和参数变更从实际姿态安全退出并重评，不复位根、物件拥有权、接触计数或保留的整理目标。拖动、Escape、几何、页面隐藏和生命周期仍须核对后显式继续；解除许可或输入占用不覆盖其他暂停。工作释放先核对原整理目标，再恢复已开启的人格日常。所有选择、表现、导航和接触共用已有身体 tick，无第二调度器。

## 验证边界

反馈回归先复现普通停留必坐、空地图随机路线、同参数无人格差异，以及坐姿退出弯腰 20°，再验证对象失效、视线不齐不能结算、近期对象不重复、实际词表／rig 表现。隔离浏览器与临时 profile 原生包含真实坐姿退出、同种子及同参数对照、现场移动对象和工作抢占。完整 inbox、导航／连续动作、生活工作与表现回归分别执行；物理设备、真实模型、三平台 CI 和主观观感分别结算。
