## 制作约束

沿用[仓库制作流程](art-workflow/README.md)：需求卡 → 内置 image_gen 原画／编辑 → 只读结构检查 → 拆件／网格绑定 → 实际渲染慢放／逐帧 → 产品装配回归。新栅格资产使用内置工具，保存完整提示词、参考摘要、原图、候选判定和导出摘要。原角色资产与第三方声明不改写。可编辑交付采用原始 PNG 分层图集与 JSON 的等价源文件；这不是 Cubism 的 `.cmo3`／`.moc3` 导出。

参考 Live2D 官方[素材拆分](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)与[PSD 注意事项](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)：拆件稿与导入稿分开，补画被遮挡的部分，部件独立且名称稳定。此项目继续使用现有 WebGL 网格与变形树，不在本轮更换 Cubism 运行时或引入平台专用 SDK。

坐标仍为原 rig 空间：脚下 `(128,256)`，统一缩放，不剪掉尾部与呆毛。每方向记录可见边界、脚底、头／视线、气泡和命中范围。行进向量、身体朝向、视线独立；低速保持方向，转身避免全身宽度缩为零或长时间双图交叠。持物／接触动作在校准前继续使用原模型。

主配色方向身体是默认接入对象；其他配色及尚未校准的持物、坐卧动作必须走明确且可打断的原模型兼容路径。任何新方向都必须先在实际网格绘制中复核，未通过的候选留在制作目录，不进入默认产品。

## 产品接入完成条件

- 默认主页面使用分发包内的方向资源，由同一导航轨迹选择正面、背面及左右斜向；静止留意用户可回正面，视线独立。
- 转身保留脚下原点与步态相位，低速不抖动，不把全身缩为零或长时间叠成双影；左右不对称头饰保持角色身份。
- 接触、持物、坐卧、手势及其他配色采用明确的兼容路径，实际绘制的手部仍是接触事实来源；切换、打断、恢复无第二个身体或时钟。
- 真实产品覆盖纵向／对角路线、停留、拖放、跳跃、尺寸、生命周期、工作交接和旧角色；执行完整 `test:inbox-ui` 及核对源码后的 macOS VM 原生回归，并核验包内资源。其他平台与用户观感按实际结果结算。

## 设计图到绑定的校准

D1-C06：正面与右斜后以用户给出的设计原图为比例基准，按共同脚底和全身高度转换母版坐标，登记部件框、关节、五官、头结及必要的静态网格补偿。首轮只校准绑定，随后 C07 补齐源稿造型；前述去尾钩和遮脸仍保留。制作台提供设计／实际／叠加切换，回归同时检查真实网格轮廓及可见眼睛落点，生产身体采用同一导出，不能仅用“能眨眼、能走路”代替设计一致性。

拆件重绘与原五官纹理仍有线条／色彩细节差异；轮廓指标不代表逐像素一致，也不代表用户已验收。当前校准范围为本次两张设计，背面和原斜前不冒用这项对照结论。
