# 第 5C 期：回应与安静节奏

状态：2026-10-21 用户授权在新 session 开始下一阶段；本页是本期执行范围，尚无 5C 实现或验证结论。当前任务与基线见[开发状态](../aliveness-development.md)。在 `codex/aliveness-foundation` 的默认产品主页面交付实现、测试、说明和本地提交，不推送、合并或发布。

## 可见闭环

连续抚摸先保留即时身体反馈；一个短时互动片段稍后至多形成一个有效的交流回应。用户忙于任务、输入或阅读时保持安静；恢复空闲后先核对事实，过期或失效的候选直接丢弃，不集中补播。用户应能区别当场被摸到的反应、互动已保存的事实和一次经过合并的稍后回应。

本期复用[可信抚摸／明确回应活动](../companionship-contract.md)与[5B 存档](companion-memory-contract.md)。单次存档成功提示已经实现，但还没有合批队列。不得把原行为换个名字作为本期交付。

## 实施边界

- 先交付默认产品的抚摸合批与回应许可，复用现有调度，不新增另一套心跳、模型调用或上游模型事件总线。二维制作预览和默认二维产品装配不在本期。
- 身体反射保持即时，标记已执行的反应，稍后交流不重演反射；记忆准入、关系计分和邀请预算独立结算，不因合批重复记账或扩大权限。
- 使用有界、仅运行期的候选，至少绑定角色／页面代次、来源事件身份、时刻、已反应／保存状态和失效条件；同类片段合并，至多保留一个待表达的抚摸回应。合并窗口、有效期和资源上限由实现明确为常量并写入本契约，不照抄上游参数，也不留无界数组。
- 仅凭存档所有者确认的事件声称记住；写失败、冲突、删除／纠正、旧记忆代次、换角色和迟到回执不得复活或错绑候选。没有经历时不编造记忆，不读聊天／工作正文或推断用户画像。
- 工作、审批／异常、输入 active／unknown、阅读／草稿／发送、拖动、休息、隐藏／挂起与减少动态保持优先。占用时按明确规则等待或丢弃，期限不因每帧重评无限延期；解除占用仍需检查当前许可。
- 显式“回应她”的活动与保存回执保留用户操作优先级；不要让合批队列吞掉手动互动、接管原工作回复、改变驻留计时或制造收件箱未读。
- off 停止候选；quiet 不自动邀请；interactive 仍沿已有低频预算、“稍后／今天安静／恢复”和完整词表。拒绝与缺席不扣关系，重启不恢复旧队列或补算活动。
- 沿[近身便笺视觉规则](message-visual-system.md#近身互动提示)，不引入新的宽横条、外框滚动条或新素材。缺少动作词时安静降级，用户回应仍可键盘操作。

## 交付与验收

1. 先用当前代码复现连续抚摸多次反馈与忙碌切换，建立能检查合并／重复／过期的确定性回归，再完成本地策略和真实主页面接线。
2. 纯策略验证同类合并、不同来源去重、有界容量、时钟异常、过期、模式切换、删除／纠正、换角色、生命周期与迟到回执；保存失败不能出现成功记忆提示。
3. 真实浏览器展示连续抚摸 → 一次有效稍后回应；工作中安静，恢复后不集中补播过期或已抑制的反馈，仍有效的候选也必须重新获得当前许可。保留已有招呼回应与记忆查看／纠正／删除、捕获阅读、草稿／焦点／选区、在途身份和原气泡时钟。覆盖中英文、大字号、小窗口和减少动态。
4. 运行构建、类型、相关单元／脚本及完整 `test:inbox-ui`；使用临时 profile 串行验证 Electron 真实 IPC 与实际输入。旧全套原生限制另报，不以定向结果覆盖。
5. 同步本页的最终时序／上限、使用说明和当前开发状态；新报告／日志／截图绑定实际源码身份，作本地提交并提供可操作预览。自动化通过与用户观感分别结算。
