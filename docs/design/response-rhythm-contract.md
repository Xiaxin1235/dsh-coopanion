# 第 5C 期：回应与安静节奏

默认产品主页面已实现第 5C 期，使用 `web/response-rhythm.js` 的纯本地策略与既有帧调度；当前交付身份、验证与用户验收见[开发状态](../aliveness-development.md)。本契约只定义回应策略；产品空间与装配另由对应契约约束。

## 可见闭环

连续抚摸保留即时身体反应和“谢谢摸摸”近身提示；同一个短时片段合并为至多一次稍后交流。稍后回应只显示便笺，不重演身体反射，不重复保存事件、增长关系或占用邀请预算。即时提示不声称记住；保存由原存档所有者独立结算，稍后表达前同时核对对应回执和当前确认条目。至少一条来源仍确认保存才提示已保存相处记忆；全部写失败只说明没能保存，未返回的回执不当作失败或成功。

主页面使用可信手势识别，每个事件保留唯一 id；角色 iframe 的 touch 自报不产生候选或记忆。抚摸准入与计分冷却仍见[陪伴契约](../companionship-contract.md)，记忆准入、修订、纠正／删除和撤销代次仍见[5B 契约](companion-memory-contract.md)。没有经历时不编造记忆，不读取聊天／工作正文或推断用户画像。

## 时序、身份与容量

`RESPONSE_RHYTHM` 明确使用毫秒常量：

| 常量 | 最终值与含义 |
|---|---|
| `pauseMs` | 4,000：最近一个已纳入的抚摸后，等待短暂停顿 |
| `mergeMs` | 10,000：从片段首事件起的合并上限，也是最迟可尝试表达时刻；占用仍优先 |
| `ttlMs` | 20,000：从首事件起固定有效期，等于期限即丢弃；事件与逐帧检查均不延期 |
| `sources` | 16：一个候选最多保留 16 条来源；超过合并时间或容量的事件仍独立保存，但不再加入该回应 |
| `history` | 32：最多保留 32 个、各有效 20 秒的去重身份；满时拒绝新候选来源，不提前淘汰仍有效的身份 |

全页面至多一个待表达的抚摸候选，不建无界数组。候选绑定角色、页面／客户端 epoch、记忆撤销代次、首时刻、到期时刻；每条来源绑定唯一事件 id、发生时刻、已即时反应标记和 pending／saved／failed 保存状态。时钟非有限、负数或倒退直接撤销当前候选。回执只能更新已有匹配来源，不能重新建队；角色／epoch／记忆代次不符的回执不影响新候选。

保存成功的来源必须仍在当前所有者摘要中，原始类别为抚摸且未被纠正。删除／纠正／清空会撤销候选；打开记忆管理也主动撤销，以免管理结束后突然重提旧经历。换角色、热切陪伴模式与重载均清空队列；重启不恢复旧候选或补算活动。存档容量淘汰使已保存来源不再可确认时，整个候选安静丢弃。

## 当前回应许可与中断

工作、审批／异常、输入 active／unknown／超过 2.5 秒未更新、正文阅读、收件箱阅读、草稿／发送、按住／拖动、身体忙碌／移动，以及显式活动／邀请／其回执均优先。占用期间只等待同一个固定期限内的候选；恢复时重新核对当前所有许可，不集中补播。候选等待期间暂停新自动邀请的准入，不消耗预算或改变邀请的既有驻留期限。

关闭陪伴、关闭闲时走动、休息、隐藏／挂起、减少动态效果、换角色和记忆管理直接撤销候选。已经表达的便笺显示 3 秒；被输入或其他占用收起后不重显，不重置原任务气泡的计时，不制造收件箱未读。普通浏览器预览的全局键盘状态为 unknown，因此保持即时抚摸和真实存档，但不会自动表达稍后便笺；受控浏览器回归明确注入粗粒度 idle，原生使用现有系统适配器。

显式“一起活动／回应她”与保存回执保留 5B 操作优先级；发起活动先撤销抚摸候选。off 不产生新候选，quiet 不自动邀请；interactive 沿现有低频预算和“稍后／今天安静／恢复”规则。拒绝与缺席不扣关系。无新心跳、模型调用、画像、素材或动作词；现有动作缺词仍按既有安全回退，稍后交流不会强发身体词。视觉沿[近身便笺](message-visual-system.md#近身互动提示)，键盘仍可操作显式回应。

## 验证入口与边界

- `tests/response-rhythm.test.js`：合并、去重、来源／历史上限、固定有效期、时钟异常、当前许可、过期、失效与迟到回执。
- 完整 `npm run test:inbox-ui` 包含真实主页面抚摸、当前许可、失效撤销、写失败与中英文大字号小窗口，保留 5B 明确回应及记忆管理、捕获阅读、草稿／焦点／选区、在途身份和原气泡时钟回归。策略时间和输入枚举受控，身体、指针、HTTP 与存档保持真实。
- `COMPANION_EVIDENCE_DIR=<新目录> node tests/response-rhythm-native.mjs` 使用隔离 Electron profile、真实 IPC、可信指针与实际时钟，验证两次抚摸合批、20 秒忙碌过期和手动活动优先；已接入 `test:desktop` 串行执行。物理键盘操作与跨平台验收独立。
- `tests/companionship-native.mjs` 保留明确回应、真实存档、重启与查看／纠正／删除的独立原生检查。
