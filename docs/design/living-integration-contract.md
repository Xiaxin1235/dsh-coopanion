# 默认产品：桌面生活与环境响应

2026-10-22 按用户对帧率、空抓、探索链条、屏幕遮挡和环境互动的反馈修正；当前交付与验收从[开发状态](../aliveness-development.md)结算。复用前期空间、连续动作、唯一生活／工作协调器、人格、可信记忆与回应，不新增模型调度或独立身体心跳。

## 默认空间与生活循环

默认不摆放常驻小屋和珊瑚，只保留身体、有限活动范围、用户设置的停靠位置和一枚小贝壳。制作预览保留原布局／资源；可见物件与桌面边界、停靠位置这些明确空间用途，才可以成为生活目标，不生成匿名随机空地点或对不存在的家具假装观察。

先实际观察贝壳，再尝试一次整理。只有导航回执、实际位置、速度、稳定接触和手部开合共同提交拿放；耗时不证明进度。归位后保留完成标记，不反复拿放。随后外出观察活动范围边界，经真实抵达、视线对齐和有效观察确认，返回指定停靠点，清醒休息，再进入下一轮。安静／活泼改变停留、关注与恢复后的休息间隔；步行与观察都经同一协调器，工作和用户接管保留未完成目标。

运行期最多一个明确访问目标，具有 token 和几何修订；旧观察、旧路线、换目标或旧几何不能完成新目标。最多 8 个对象观察标记、16 条选择说明，仍由前期人格模块限定；整理、循环计数和等待只在运行期保留，不补算离线活动。

## 环境产生可见的因果

- 键盘 active：安全退出／真实落物后在当前附近安静守候、抬眼留意；短暂停顿不立刻再走，至少 8 秒连续 idle 后重新获准。unknown 继续保守暂停。
- 鼠标接近实际身体范围：交接后留意实际鼠标位置，必要时转向；不追逐鼠标，也不为每次小移动重开抓取或导航。离开至少 1.2 秒后再评估。
- Host 工作：来自 WorkSources 的进行、工具、审批、问题、continued、异常和完成元数据决定工作关注；真实交接与原生活目标续接保持。预览不连接 Host 时明确标注受控事实，不能据此宣称感知其他应用的工作内容。
- 生命周期：隐藏、锁屏／休眠及来源未知暂停；可信恢复后安全接续，并至多一次短促注意反馈。恢复候选 15 秒失效，不能在长时间工作后补演旧事件。
- 实际几何变化和拖动：旧导航失效，按现位置和当前合法几何重评；物件保持拥有权，身体保持可见，原生跨显示器拖放继续沿现有协议，自主跨屏不扩展。

感知范围只有已存在的位置、粗粒度输入、工作元数据和生命周期，不读取屏幕截图、按键正文、前台应用／窗口内容。反应不写关系分数、相处经历或邀请预算，也不调用模型。显式活动、抚摸与保存确认、记忆删除／纠正／代次撤销沿用 5B／5C。

## 帧率、姿态和拥有权

主页面仍使用既有单一帧调度。只有完全空闲的身体才采用 30fps 绘制上限；根不动的接触、手部、抬起／放下、姿态过渡和视线对齐也属于活动，按当前显示回调更新，不能仅用根位置的 moving 判断。

空手站立的暂停／恢复不经过物件收手；真正抓取、弯腰或持物的打断仍从当前姿态退出并经真实落物提交。用户／工作／生活共用身体、导航器和时钟，协调器只释放自己拥有的手势。

正式工厂与原工作台共用 `web/upstream/kit/living-body.js`；默认人物、手部与持物同帧合成，不通过主页面搬运逐帧 PNG，不依赖安装包外的制作文件或生成工作事实模块。

## 支持和验证

90–240px 按角色比例构造几何。关闭自主生活、自定义角色或小视口保守回退简单日常，手中物件先安全交接；关闭陪伴停止自主行为。热切保留角色 frame、阅读、草稿、选区和在途请求。

工作事实最多 32 个源，容量或来源不可用时保留未决请求并暂停；完成继续复用共享 CompletionTracker，普通回复／接受回执／查看均不代替真实完成。

验证包括纯策略、真实默认主页面的完整循环／键鼠变化／不空抓、原生动作帧比例、真实拿放／工作交接与记忆、完整 inbox、旧阶段和默认窗口兼容。实际 GPU 设备、物理键盘／多屏、真实模型、长期资源及用户 LIVE 感分别验收。
