# 花箱 570/515：错误封路修正

用户反馈截图中角色 `(186,542)`、花箱 `(570,515)`、北柱 `(621,75)`、南柱初始位置形成 507px 门柱间隙，目标为 `(850,600)`。该反馈属于第 2 期模型遗漏，未推进第 3 期。

原模型在 `8d1fc7a` 可稳定复现 `disconnected-in-rectangle-model`。独立页面通过实际控件摆放后同样失败；起点与终点合法。对必须经过的 x=750 截线，禁区、岗位、花箱等扩张范围连成覆盖可用 y 的虚拟墙。搜索器没有漏掉现有模型内的合法路，错误来自把画面立面高度和完整角色屏幕高度都当成地面纵深。

修正为已标定物件分别导出立面和地面范围：身体地面占用为 200×32px，保留完整横向范围和非零纵深，加 12px；世界边界、内容禁区与未标定物件继续采用完整 200×213px 加 12px。规划、逐帧执行、拖动和动态重规划共用相同规则。实体深度排序按标定地面底缘，允许不同纵深的合理遮挡；不移动或取消障碍、不减小内容禁区、不使用脚点放行。

新增回归先在旧实现失败；修正后通过同一输入实际绕行至目标，只有一次到达回执。针对有限地面宽度、紧邻边界、薄障碍、完整身体禁区和未标定实体的回归同时保留。
