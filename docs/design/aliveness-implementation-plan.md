# 生活感实施路线

本页维护阶段顺序与架构取舍，不记录会话授权、历史测试数量或待办全集。当前执行范围只看[开发状态](../aliveness-development.md)，具体行为以相应契约为准；整理前完整蓝图保存在[5B 阶段归档](../archive/2026-10-aliveness/stage-5b/README.md)。

## 1. 演进顺序

空间与美术基础 → 二维运动 → 连续动作与物件 → 生活／工作协调 → 人格、记忆与回应节奏 → 出门与关系痕迹 → 跨屏。每期交付可操作的可见闭环，不只播放动作或扩充台词。新美术由实际画面缺口驱动，见[资源入口](aliveness-art-assets.md)。

| 阶段 | 契约或规划边界 |
|---|---|
| 1–2 空间与二维运动 | [生活空间](living-space-contract.md)：地面、立面、完整禁区、导航和真实到达 |
| 3 连续动作与物件 | [连续动作](continuous-action-contract.md)：接触提交、持有、放下和中断恢复 |
| 4 生活／工作双线 | [双线协调](life-work-contract.md)：独立意图、唯一身体拥有权和真实工作事实适配 |
| 5A 人格影响行为 | [人格行为](personality-behavior-contract.md)：稳定偏好与当下情绪分开，不扩张工作或邀请权限 |
| 5B 有限相处记忆 | [记忆](companion-memory-contract.md)：可信事实、有限存档、查看／纠正／删除、可感知回应 |
| 5C 回应与安静节奏 | [本期执行范围](response-rhythm-contract.md)：即时反应、同类合批、有界候选与占用优先；默认产品已实现 |
| 6 出门与关系痕迹 | 后续候选；缺席、留言与归来须先定身份、期限和实际完成证明，不编造离线活动 |
| 7 跨屏 | 后续候选；须处理真实 workArea、混合 DPI、拖放和生命周期，不把单屏制作预览当成跨屏产品 |

## 2. 架构与装配边界

生活线保留对象、目标、步骤与进度；工作线消费可信 Harness 事实；协调模块决定身体、物件、视线、表情与社交通道的拥有权。两条意图线可保留状态，但不能同时发出身体位移。

默认产品当前使用主页面、NPC、可信互动存档；第 4／5A 期二维故事是独立制作预览。正式 Host 事实适配的受控验证，不表示默认产品已完成二维装配。模型调用、自改人格和额外角色人格均不是这些阶段的隐含依赖。

## 3. 连续执行与真实状态

到达、接触和完成由实际几何／匹配回执证明，耗时只用于节奏。打断从实际姿态安全退出，保持物件拥有权；恢复时核对原目标和当前事实，不重播已提交动作。默认 NPC 与二维执行器各按本身装配解释，不能只因词表相同就宣称共用完整协调层。

## 4. 验证与交付

实现、测试、使用说明、契约和本地提交一起交付。浏览器、受控 Host、隔离原生、系统实机、三平台 CI、正式安装／发布和用户观感分别结算。固定数字与失败过程进入[报告](../reports/README.md)，历史阶段进入[归档](../archive/2026-10-aliveness/README.md)。

## 7. 上游借鉴：人格、记忆与互动节奏

来源是[2026-10-19 固定调研](../archive/2026-10-aliveness/upstream-motion/README.md#固定调研)，不是对上游最新版本的声明。旧蓝图的参数、草拟接口及资源编号仅供追溯，不是当前 API。

| 内容 | 采用方式 |
|---|---|
| 人格与情绪 | 借鉴稳定偏好／短时情绪分离，本地策略遵守既有许可，现行规则见 5A 契约 |
| 记忆 | 本地可信所有者保存真实互动；容量、迁移、删除与撤销由 5B 契约维护，不移植上游模型存档 |
| 身体反射与稍后表达 | 复用现有 API 2 动作；借鉴先反应、后合批的时序，本地队列按 5C 执行范围实现 |
| 表现补丁 | 已择取清醒坐姿与行走摆臂补丁；不因此声明具备新关节、人格系统或二维产品装配 |
| 模型调度 | 未纳入；不引入上游模型事件总线、定时模型唤醒、自由人格或聊天画像 |
