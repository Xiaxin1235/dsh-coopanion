# 消息与阅读的视觉体系

2026-10-21 用户要求重新设计头顶输出框，消除滚动条与人物不协调的问题。当前实现入口为 `web/message-surfaces.css`，在基础 `style.css` 后加载；页面结构为 `web/index.html`。这是默认产品的消息界面改动，独立于生活感二维制作预览。

## 视觉语言：角色捎来的便笺

沿角色已有的深色轮廓、奶白衣饰和蓝色点缀组织界面。气泡、全文、未读入口和右键菜单使用同一纸面、轮廓与动作色；其他面板目前只共享外壳和部分控件配色，不据此宣称完整迁移。右键设置的组件覆盖见下表。不另画人物或增加新素材；颜色由当前角色配色关联，角色／配色切换仍沿原 `applyAppearance()` 同步。

| 语义 token | 来源与用途 |
|---|---|
| `--ui-ink`／`--ui-outline` | 角色现有轮廓色；正文与细 1.5px 外框，避免厚重黑框压过人物 |
| `--ui-accent` | 角色 accent 与轮廓色等量混合；主要动作、来源标题与焦点环，保持深色字／浅色纸面的清楚对比 |
| `--ui-paper`／`--ui-wash` | 既有奶白底与少量角色色；纸面、阅读区及次要操作底色 |
| `--ui-rule`／`--ui-muted` | 更轻的分隔线和辅助信息；不用高饱和链接色承载所有层级 |
| `--ui-radius`／`--ui-control-radius` | 面板 20px、主要控件 11px；小图标／关闭控件只做相邻尺寸的光学调整 |
| `--ui-shadow` | 两层低透明轮廓色投影；将纸面托起，保留人物作为主体 |
| `--ui-danger` | 克制的暗红混合角色轮廓色；只用于删除与清空，配合动作文字，不单靠颜色表达风险 |

间距以 8／12／16／20px 为主要节奏。正文基准 14px，阅读行高 1.85，预览 1.75；来源 12px、辅助标识 10px，均乘既有 `--text-scale`。角色大小独立。标题、正文和动作通过位置、字重、留白区分，不依赖额外动画或装饰图片。

## 信息与滚动归属

- **预览**：轻量信封标记＋回复类别／来源＋独立关闭按钮；正文单独滚动；底部按重要性区分全文与会话操作。短内容没有多余滚动；长预览和大字号仍可滚动查看，不从 DOM 删除内容。
- **全文**：沿用同一标题和纸面；时间／项目为辅助信息；中间正文是唯一滚动区，标题和底部切换／续接保持原位。代码和表格保留各自横向滚动。
- **轨道**：滚动区距外轮廓至少 8px，6px 的低对比细轨道只存在于内容区域，不贯穿关闭按钮和操作栏；Firefox 使用相同色系的 thin 回退。
- **尾部与位置**：气泡与阅读器的外层不承担滚动，因此纸面尾部可以指向原人物锚点。工作区夹取、字号后的重测量继续使用原几何与 ResizeObserver。
- **小窗口**：优先换行和缩短来源标题，动作可以换行；不缩小角色，不用 transform 缩放面板，不隐藏继续／关闭入口。
- **交互**：保留清晰键盘焦点、减少动态设置和原按钮语义；装饰 SVG 为 `aria-hidden`。提醒与待办仍使用各自真实语义，不让装饰替代状态。

## 右键设置组件与覆盖

右键菜单曾只迁移外壳和入口卡片；陪伴表单、记忆操作、开关和外层滚动仍沿旧实现，不能记为完整统一。2026-10-21 反馈修正将以下组件一起纳入 `message-surfaces.css`，保留所有既有 id、操作许可和存档语义。

| 组件 | 固定规则与状态 |
|---|---|
| 角色标题 | 42×48 头像、14px 角色名、10px 辅助说明／状态；关闭按钮独立，标题可换行 |
| 操作入口 | 11px 圆角、轻色纸面、20px 线性图标；12px 标题与 10px 说明，统一 12px 内距 |
| 陪伴表单 | 12px 标签、独占一行的原生选择框、11px 说明；仍用原生选择语义和键盘操作，不自造下拉交互 |
| 动作层级 | 主要操作深色底；纠正／恢复使用轻色底；删除／清空用 `--ui-danger`；32px 最小高度，按钮换行 |
| 禁用状态 | 显式使用轻色底和辅助文字色、保留边框，不依赖浏览器默认灰色与透明度；既有 `disabled` 决定能否操作 |
| 记忆分组 | 原生 details／summary，统一线性折叠标记；空／不可保存提示沿原状态文案，不伪造数据 |
| 记忆条目 | 列表去编号，以细线分隔；12px 类型／纠正标记、10px 本地时间、独立操作行；最多 16 条沿可信存档控制 |
| 偏好开关 | 单列设置行；统一 20px 图标、12px 标签、10px 说明和 28×16 开关；选中态用语义强调色，保留 `role=switch`／`aria-checked` |
| 滚动 | 标题与底栏固定，`.menu-content` 是唯一纵向滚动区，距外框至少 8px；记忆列表不再嵌套滚动，区域可聚焦并用键盘滚动 |

菜单沿 8／12／16px 间距排布，宽度随文字档位增大且受 viewport 限制，高度最多 720px 且不超过窗口可用高度，不放大角色。展开记忆只增加正文区内容，避免在大窗口无限拉长纸面遮住角色；小窗口优先保证操作可达。不把滚动轨道推到外框，也不让关闭／隐藏入口离开视野。字号热更新保留菜单内已有记忆节点、焦点和操作身份；角色／摘要变化仍按原刷新边界处理。

## 保持的契约

消息改动只调整 HTML 层级与 CSS；设置修正额外把 `pet.js` 的记忆条目呈现拆为类型、时间和操作组。`bubble-text`、`bubble-status`、关闭／全文／会话、reader 正文及菜单控件 id 保留；阅读、发送、未读、任务完成、计时、记忆请求与撤销逻辑不变。原始回复继续完整保存，预览仍沿原 180 字符规则；打开全文本身不切换关注会话。

字号／语言、工作快照和新结果的热更新仍遵守[文字契约](../text-readability-contract.md)与[会话契约](../session-chat-contract.md)。不能为了样式重建正在阅读的正文、清空草稿、重置滚动、重放旧回复或延长驻留时间。
