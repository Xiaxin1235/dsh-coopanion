# 消息与阅读的视觉体系

2026-10-21 用户要求重新设计头顶输出框，消除滚动条与人物不协调的问题。当前实现入口为 `web/message-surfaces.css`，在基础 `style.css` 后加载；页面结构为 `web/index.html`。这是默认产品的消息界面改动，独立于生活感二维制作预览。

## 视觉语言：角色捎来的便笺

沿角色已有的深色轮廓、奶白衣饰和蓝色点缀组织界面。气泡、全文、未读入口、菜单和其他面板共用纸面、轮廓、阴影与控件规则，不另画人物或增加新素材。颜色由当前角色配色关联，角色／配色切换仍沿原 `applyAppearance()` 同步。

| 语义 token | 来源与用途 |
|---|---|
| `--ui-ink`／`--ui-outline` | 角色现有轮廓色；正文与细 1.5px 外框，避免厚重黑框压过人物 |
| `--ui-accent` | 角色 accent 与轮廓色等量混合；主要动作、来源标题与焦点环，保持深色字／浅色纸面的清楚对比 |
| `--ui-paper`／`--ui-wash` | 既有奶白底与少量角色色；纸面、阅读区及次要操作底色 |
| `--ui-rule`／`--ui-muted` | 更轻的分隔线和辅助信息；不用高饱和链接色承载所有层级 |
| `--ui-radius`／`--ui-control-radius` | 面板 20px、主要控件 11px；小图标／关闭控件只做相邻尺寸的光学调整 |
| `--ui-shadow` | 两层低透明轮廓色投影；将纸面托起，保留人物作为主体 |

间距以 8／12／16／20px 为主要节奏。正文基准 14px，阅读行高 1.85，预览 1.75；来源 12px、辅助标识 10px，均乘既有 `--text-scale`。角色大小独立。标题、正文和动作通过位置、字重、留白区分，不依赖额外动画或装饰图片。

## 信息与滚动归属

- **预览**：轻量信封标记＋回复类别／来源＋独立关闭按钮；正文单独滚动；底部按重要性区分全文与会话操作。短内容没有多余滚动；长预览和大字号仍可滚动查看，不从 DOM 删除内容。
- **全文**：沿用同一标题和纸面；时间／项目为辅助信息；中间正文是唯一滚动区，标题和底部切换／续接保持原位。代码和表格保留各自横向滚动。
- **轨道**：滚动区距外轮廓至少 8px，6px 的低对比细轨道只存在于内容区域，不贯穿关闭按钮和操作栏；Firefox 使用相同色系的 thin 回退。
- **尾部与位置**：气泡与阅读器的外层不承担滚动，因此纸面尾部可以指向原人物锚点。工作区夹取、字号后的重测量继续使用原几何与 ResizeObserver。
- **小窗口**：优先换行和缩短来源标题，动作可以换行；不缩小角色，不用 transform 缩放面板，不隐藏继续／关闭入口。
- **交互**：保留清晰键盘焦点、减少动态设置和原按钮语义；装饰 SVG 为 `aria-hidden`。提醒与待办仍使用各自真实语义，不让装饰替代状态。

## 保持的契约

本轮只调整 HTML 的消息层级与 CSS。`bubble-text`、`bubble-status`、关闭／全文／会话按钮、reader 的正文与操作 id 保留；未修改 `pet.js` 的阅读、发送、未读、任务完成和计时逻辑。原始回复继续完整保存，预览仍沿原 180 字符规则；打开全文本身不切换关注会话。

字号／语言、工作快照和新结果的热更新仍遵守[文字契约](../text-readability-contract.md)与[会话契约](../session-chat-contract.md)。不能为了样式重建正在阅读的正文、清空草稿、重置滚动、重放旧回复或延长驻留时间。

- 完整 `test:inbox-ui`：捕获全文、长代码／表格、草稿／选区、在途身份、原气泡计时、NPC 与多屏回归。
- `scripts/check-package.mjs` 将新样式表列为必需资源，包文件清单可用 `npm pack --dry-run --json --ignore-scripts` 检查；这不是安装或发布验收。

实际结果从[当前开发状态](../aliveness-development.md)及对应固定报告查阅。自动布局检查、隔离原生、真实设备和用户审美验收分别结算；视觉体系本身仍可根据实际观感继续微调。
