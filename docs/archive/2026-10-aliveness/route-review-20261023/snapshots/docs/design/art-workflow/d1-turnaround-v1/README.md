## 现行外观与尾巴约束

2026-10-23 用户在否决过小、过大两个方向后，明确选择最新单人参考。它替代此前三视图、神态插画及缩小／放大尺寸方案的设计优先级。

- 身材、柔和脸形、蓝色长发、纤细弧形呆毛、女仆头饰、深蓝／白／少量金色服装与鞋袜，均参照最新原图。保持参考的轻盈线条，不回到旧版大头、亮青色和粗线风格。
- 尾柄有长度与厚度，**在裙后弯曲，末端上扬**，体量跟随原图与身体的关系。不能再按任意裙宽倍数放大或缩小，也不能把它拉成向后笔直伸出的巨尾。
- 蓝鲸尾巴是尾柄连接左右两片尾鳍，尾背蓝色、腹面浅色。弯曲尾柄带动尾鳍改变姿态，侧视会有重叠；不强迫每个视角都展示对称平摊的双鳍。
- 解剖连接点固定在骨盆后中线并藏在衣服内，近端沿背侧延续到**后裙摆中部**再露出，随后侧弯；“裙下出尾”不等于在侧裙边接一截尾巴。从背面看，裙摆遮住根部，露出的近端遮住对应上腿；正面则由裙与腿遮住尾根。不得通过抬裙、露更多腿或另接三角片完成连接。腰结仅帮助定位背部中线，不充当尾根。
- 四方向旋转同一个身体与尾巴姿态。斜后应重新投影同一连接和弯曲关系，不是把正背轮廓换一侧粘贴。正背／斜后以头发遮住脸，不靠缩小后脑来遮脸。
- 最新图只提供一个视角；侧后服装细节、尾鳍背面的形状与遮挡需要推演，仍属于待审设计，不能称为从参考已测得的事实。转面采用放松站姿，原图挥手作为表情／姿态参考保留。

`source/manifest.json` 区分当前参考、候选与历史。`reviewCandidate` 只选择展示图；`lockedMaster` 为空、`productExportAllowed` 为 false。只有方向身份、尾巴体量和遮挡通过可见审阅后，才进入 R02 保留原画坐标的拆层。

## 当前候选

用户指出 v11 的尾巴逻辑位置仍不对，该稿已拒绝。问题是尾根与骨盆／裙摆／腿的连接和遮挡，不是画面左右。v12 因抬裙与近端尖片失败；v13 虽从未抬裙的 v11 重试，仍改动斜后裙摆、保留错误的正背连接。两版均不放行，保留原图作为反例。v14 单独画出连续中部尾柄后，仍因抬裙未通过。v15 恢复普通裙摆，保留下面连续露出的近端，作为**独立正背连接结构候选**；不是四向母版，也不证明与旧稿像素一致。v16 依据 v15 推演独立斜后接点与遮挡；两张在工作台并排展示，均待审，不是同一三维模型自动投影。

当前可见改进是后裙摆中部的连续近端及其遮腿关系。剩余门槛是尾鳍透视、全方向身体／发束／服装一致性与用户观感；不把结构稿直接拼入产品。原图为 `source/tail-back-structure-v15.png`、`source/tail-oblique-structure-v16.png`，对应完整提示词分别为 `source/prompt-tail-back-structure-v15.txt` 与 `source/prompt-tail-oblique-structure-v16.txt`，均由内置 image_gen 制作。

工作台支持斜后和正背分别放大尾根，青色路径／圆点标示手工估计的衣内走向与预期出口。标记是制作推演，不是实测骨骼，更不证明候选已经匹配。
