这轮核对什么

  • 同一脸形、头部体积、发束、服装与头身比；斜后和正背不露脸。
  • 尾巴长度、厚度、弯曲和体量与上方参考相符，四个方向不各自变形。
  • 尾根藏在骨盆后中线，近端从后裙摆中部出现；背视时遮住相应上腿，再向侧方弯曲。
  • 两片鲸尾鳍随弯曲尾柄改变朝向，侧视允许重叠。

母版尚未锁定
