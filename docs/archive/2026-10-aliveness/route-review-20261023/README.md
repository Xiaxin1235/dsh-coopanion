## 顺手修复的清理器缺陷

运行 `cache:clean` 预览时，Finder 的 `.cache/runtimes/.DS_Store` 被当成目录读取 `ready.json`，触发 `ENOTDIR`。临时目录／运行时枚举现先核对真实目录，再读元数据；普通未知文件保留，符号链接仍受原安全边界约束。新增回归同时验证普通文件不会阻塞合法候选，也不会被删除。修复后真实缓存预览为 0 个候选，没有执行缓存批量删除。
