# 第 5B 期：有限相处记忆

当前范围与交付结果见[开发状态](../aliveness-development.md)。记忆复用默认产品现有的本地主页面、可信存档与显式互动闭环；第 4／5A 期二维制作预览仍独立，不因本期接通默认二维产品装配。

## 事实与可见行为

只接收主页面实际确认的抚摸，或用户发起且真实完成的一起活动。角色 iframe 的 touch、自动日常、任务完成、发起未完成、取消及超时均不能写成经历。来源身份、原始类别、可信所有者时刻和写入修订随条目保存；角色 id 由外层分组绑定。记忆与关系成长分别结算：冷却中的真实互动可以留下记忆，但五分钟／每日上限、熟悉度解锁和邀请预算不增加。

右键菜单 → **相处记忆** 显示当前角色条目，可纠正为两类显式互动之一、删除单条或清空。纠正保留原始类别和来源身份，另存用户确认类别；后续展示和招呼使用纠正值。无自由文本、人物画像、聊天／工作正文或模型总结。用户偏好仍由已有全 profile 设置管理，换角色不丢失，不复制成推断画像。

最近有效的“一起活动”可使下一次已获准的邀请招呼在挥手后多一个现有点头；熟悉招呼的爱心仍按原解锁规则保留。缺 nod 回退原招呼，缺完整词表沿原能力降级。quiet／off、工作、输入 unknown／active、阅读、休息、拖动、隐藏及减少动态继续优先。不新增调度、模型调用、邀请候选或系统通知；记忆本身不产生回应队列。5C 合批回应仍未实施。

关闭陪伴后仍能查看、纠正和删除已有记忆。打开记忆属于用户占用，当前一起活动若被打断不记成功。菜单显示存档所有者确认后的摘要；写失败不新增条目，冲突刷新修订且不重放互动。换角色立即清空旧视图，异步回执继续绑定原角色和页面代次。

## 可感知闭环

2026-10-21 反馈修正将一起活动从自动播完改为角色先招呼 → 等待用户点“回应她” → 角色开心回应 → 存档确认。单纯等待、取消或超时不算完成，不创建记忆或增长关系。抚摸仍沿原可信手势规则。

只有存档回执的条目中包含本次唯一事件 id，才显示“这次我记住了”；未写入则明确说明没能保存。开心或动作结束不是存档成功的证明。关闭陪伴、换角色或被工作／阅读等收起的反馈，不由迟到回执复活。

下一次用户主动开始时，等待回应的小气泡会按最近条目的原始／纠正后类型提到“记得上次一起玩”或“记得上次的摸摸”；没有记录就显示初次招呼，不凭关系分数编造经历。纠正／删除／过期后从当前可信摘要重新派生。原有低频邀请的点头变化仍保留。这些是固定本地文案与现有动作，不新增自由文本、模型推断、调度或 5C 队列。

## 容量、迁移与删除

`CompanionStore` 使用 schema 2，原数据目录名称保持 `companionship-v1`。schema 1 读取时仅在内存迁移，保留关系、预算、quiet、幂等身份及修订，不把已有关系分数编成历史记忆；下一次成功变更才原子写成 schema 2。损坏、未来 schema、锁冲突和写失败沿现有降级规则处理，保留原字节。

每角色最多 16 条，全 profile 最多 128 条，超过时按写入修订淘汰最旧条目；保留期 30 天，读取隐藏过期条目，下一次成功变更清理。关系记录与记忆／撤销记录分别最多覆盖 256 个角色，整个存档最多 256 KiB。撤销代次不因容量淘汰而回收；达到角色上限拒绝新增，不能通过回收撤销标记让旧事件恢复资格。

事件在发生／活动发起时捕获当前记忆代次，一起活动到真实完成后才提交。纠正、删除、清空及卸载角色会轮换并持久保存该角色的撤销代次；此前捕获的事件即使携带最新修订，或已退出最近 128 个幂等身份窗口，也不能再写入记忆。新真实互动从新代次开始。删除详情不会撤销已结算的关系分数；卸载角色仍删除关系，但保留空的撤销标记。没有另存记忆摘要／缓存可以重建已删条目。

单写、串行、修订检查及临时文件原子替换继续由同一存档所有者负责。老客户端未携带记忆代次时只走原关系接口，不创建记忆。主 frame IPC／同源 HTTP 均沿现有来源和已安装角色检查；角色包无存档权限。

## 验证入口

- `tests/companion-memory.test.ts`：容量、独立计分、重复、迁移、纠正／删除、跨重启撤销、写失败／冲突／多实例和损坏／未来 schema。
- `tests/companion-client.test.js`：角色代次、排队前捕获记忆代次和活动原代次。
- `tests/companion-http.test.ts`：同源、角色存在与有限纠正类型。
- `tests/companionship.test.js`：招呼变化、缺词及 quiet 边界。
- 完整 `npm run test:inbox-ui` 包含真实活动完成、重载查看／纠正／删除、原有草稿／阅读／输入身份及抚摸准入回归。
- `COMPANION_EVIDENCE_DIR=<新目录> node tests/companionship-native.mjs` 使用临时 profile 检查 Electron IPC、真实活动、跨重启、纠正和删除，与其他原生操作串行。

浏览器、隔离原生、真实物理设备、三平台 CI 和主观观感分别结算；本期没有新分发包、安装或发布结论。
