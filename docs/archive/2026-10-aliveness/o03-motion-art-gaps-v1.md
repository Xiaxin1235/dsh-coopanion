# O03 动作样片：美术缺口与补充条件

依据实际模型结构及本轮试摆画面记录。本轮已用现有素材连接可重复的俯身拿放；后续资源对准局部问题。

后续状态：[手型与遮挡补齐](../../design/art-workflow/o03-shell-hands-v1/README.md)已完成本表第一项的三种手型、腕部标定与指尖前后遮挡，并将拿起／释放绑定到实际闭合／张手状态。下表保留为最初样片的缺口记录；肘膝与极端遮挡仍按其注明的触发条件解释。

| 问题与画面依据 | 当前能力 | 补充资源与启用条件 |
|---|---|---|
| 缺少张手、握住、松手的独立轮廓；[接触持有](../../design/art-workflow/o03-shell-motion-v1/screenshots/pose-contactHeld.jpg)与接触前主要靠物件区分 | 接触后短暂停留，袖口覆盖握持边缘；持物可读，但看不到手指闭合 | **优先补充**同一透视的伸手／握持／放松手型、手腕对齐点与前后遮挡蒙版。先做一侧，另一朝向镜像，不新增整个角色 |
| 手臂仅肩部整段旋转，伸手与[收手](../../design/art-workflow/o03-shell-motion-v1/screenshots/pose-retract.jpg)走肩部圆弧 | 可完成轻物件的一手拿放；袖口与物件连接持续保持 | 需要明显探手或贴身托举时，再补前臂／手掌分层、肘部遮盖和肩肘腕锚点；本轮未做独立屈肘 |
| 腿部以网格压缩表现下沉；见[俯身](../../design/art-workflow/o03-shell-motion-v1/screenshots/pose-contact.jpg) | 轻微下沉、腰部前倾，脚底固定，裙摆保留站立画法 | 深蹲、跪姿或更低物件有需求时，再补屈膝腿部及对应裙摆；当前贝壳接触无须先制作深蹲全套 |
| 腰、袖口与长发的极端遮挡只覆盖当前 20° 俯身和手臂范围 | 本轮固定尺寸样片能完成拿放，未观察到必须重画躯干才能继续的断层 | 扩大角度、换方向或尺寸后逐姿势复查，出现实际裂口再补腰部／袖口内侧／发丝遮挡；这些候选不算已确认缺陷 |
