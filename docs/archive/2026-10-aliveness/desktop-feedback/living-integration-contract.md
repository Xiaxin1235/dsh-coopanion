# 默认产品：自主生活装配

2026-10-21 用户授权打通已完成阶段，解决默认产品机械、偏响应式的体验。本轮实现；验证及用户验收从[开发状态](../aliveness-development.md)结算。沿当前分支本地实现、验证和提交，保留旧制作页与用户布局；不扩出门、跨屏、自由画像或模型调度。

## 可观察闭环

默认内置角色在许可开启时，有自己的物件与有限生活目标：留意贝壳、把未归位的贝壳整理到小窝附近、观察花箱或小窝、安静停留。目标由物件当前状态和已有观察进度选择，不按固定地点无限往返，也不重复搬动已整理好的贝壳。安静／活泼影响关注和接近方式；真实相处记忆影响下一次生活选择，不凭分数或自动活动编造经历。

工作、显式互动和阅读／输入仍优先。生活目标与实际物件拥有权保留，安全交接后由同一协调器到岗；释放后核对原对象和当前事实再续接。只有真实导航、稳定接触与手部开合提交才算拿放。几何、角色、生命周期与记忆撤销使旧身份失效。无新计时心跳或并行身体调度。

## 装配与兼容

从制作预览提取共享动作身体至 `web/`，默认产品和旧工作台跨同一接口使用。正式运行不依赖 `docs/` 或生成的工作事实模块；动作／手部／物件复用已有资源。身体内同一帧合成，运行时不持续传递 PNG 帧。默认产品使用透明、有限占地的小窝／花箱／贝壳，坐标随 viewport 与既有小窝参数重建，不读取屏幕内容。

生活小景开关允许回退到原横向 NPC；自定义角色、过小视口及缺少能力时保守回退。关闭陪伴仍停止自主行为。设置热切保留原 frame、阅读、草稿和在途请求。人体、物件和命中均来自真实根位置。

工作事实由可信 Host 的既有 `WorkSources` 所有者提供无正文元数据，经现有 IPC 快照传到主页面；完成仍使用共享 CompletionTracker，不由角色或网页消息自报。只有旧版快照时以已有工作／请求占用保守交接，不自行推断目标完成。

相处存档仍只接收真实抚摸与明确回应后完成的活动；自动整理／观察只产生运行期进度，不增加关系、写相处记忆或消耗邀请预算。记忆变更后撤销旧关联，仅使用当前确认摘要的有限类别，不读取正文。

## 策略边界

每个身体运行期先观察再尝试一次整理，归位成功后不重复搬动；约 65 秒有效生活后允许一次清醒休息，再接回对象关注。重载不补算离线生活。模式 off／输入 unknown／阅读和草稿占用暂停，许可恢复从当前姿态和对象重评；接触失败、目标阻塞等错误不盲目重试。

工作事实最多 32 个源，容量失败保守暂停并保留未决请求；不丢弃仍未结算的源来换取生活活动。正式 Agent 替换的 epoch、修订与所有者闭包隔离迟到事件；运行时问题也保留占用，continued 以投影结算。新完成仍来自共享完成判断，异常确认绑定实际源代次与修订。

小景按当前 90–240px 角色比例构造；几何变化暂停旧导航，修订后重评，并将越出视口的身体安全夹回可见区域；物件仍由实际拥有者持有。小视口不启用二维规划。关闭小景时，已经拿起的物件先真实落地、收手后再交回简单日常；快速撤销关闭可继续当前目标。

## 验证目标

纯策略覆盖自主目标、完成后不重播、当前几何、记忆代次和中断。真实主页面在无人点击时实际观察／拿放，并完成持物时工作交接与原目标续接；验证模式、人格、输入／阅读／草稿、手动活动、拖动、尺寸、语言和 reduced-motion。沿用空间与动作回归、完整 `test:inbox-ui`、构建／类型／单元；隔离原生串行验证真实 IPC 与系统输入枚举。新证据绑定实际源码、平台及本地包，自动化与用户 LIVE 感分别验收。
