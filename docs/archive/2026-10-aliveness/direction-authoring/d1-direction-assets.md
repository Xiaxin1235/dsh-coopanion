## 制作约束

沿用[仓库制作流程](art-workflow/README.md)：需求卡 → 内置 image_gen 原画／编辑 → 只读结构检查 → 拆件／网格绑定 → 实际渲染慢放／逐帧 → 产品装配回归。新栅格资产使用内置工具，保存完整提示词、参考摘要、原图、候选判定和导出摘要。原角色资产与第三方声明不改写。可编辑交付采用原始 PNG 分层图集与 JSON 的等价源文件；这不是 Cubism 的 `.cmo3`／`.moc3` 导出。

参考 Live2D 官方[素材拆分](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)与[PSD 注意事项](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)：拆件稿与导入稿分开，补画被遮挡的部分，部件独立且名称稳定。此项目继续使用现有 WebGL 网格与变形树，不在本轮更换 Cubism 运行时或引入平台专用 SDK。

坐标仍为原 rig 空间：脚下 `(128,256)`，统一缩放，不剪掉尾部与呆毛。每方向记录可见边界、脚底、头／视线、气泡和命中范围。行进向量、身体朝向、视线独立；低速保持方向，转身避免全身宽度缩为零或长时间双图交叠。持物／接触动作在校准前继续使用原模型。

先做主配色空手最小样片，不把颜色回退、多方向持物、睡坐等尚未制作的状态标成已支持。任何新方向都必须先在实际网格绘制中复核，未通过的候选留在制作目录，不进入默认产品。
