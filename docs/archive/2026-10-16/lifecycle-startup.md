# 冷启动锁屏与未知初态

> 历史快照：形成于 2026-10-16，归档于 2026-10-19。下文的候选、发布进度、未完成项和操作只描述当时记录；当前工作以用户请求和现行契约为准。

2026-10-16。固定来源、候选包摘要和结果见 [validation.json](../../evidence/p1/lifecycle-startup-20261016/validation.json)，原始文件摘要见 [SHA256SUMS](../../evidence/p1/lifecycle-startup-20261016/SHA256SUMS)。这里的发布前候选与最终分发包分别结算。

旧包在本机已锁屏时正常沙箱冷启动仍判为可活动，新实现的同场景检查通过。macOS 只读取三个聚合会话标志；Windows／Linux 使用宿主系统空闲状态。不可识别的初态保守挂起，收到明确解锁事件后才恢复，避免未知被当作可活动。

本机 237 项单测、12 项 Node 检查和完整原生回归通过（另 1 项平台跳过）。原生受控场景覆盖锁屏、未知初态、锁屏恢复及系统初态探针。三平台 CI 的 Linux／Windows 初态已知未锁屏；托管 macOS 初态 unknown，按契约保持挂起。这不等于托管 macOS 的可交互控制台或 Windows／Linux 物理锁屏、休眠、唤醒验收。

实际日用安装的原始诊断、配置备份和周末样本只保存在本机私有目录。周末自然生命周期观察尚未结束，启动与通过不混同。
