# 本地自主陪伴契约

本文定义 NPC 日常、低频邀请与关系存档。支持的宿主版本以 `package.json` 为准；产品随 Harness 运行。

## 配置与感知

`companionship: off | quiet | interactive` 默认 `off`。off 停止自主行为；quiet 使用 NPC 日常和显式互动；interactive 额外允许低频邀请。三种模式均关闭角色引擎的随机漫游。内置鲸鱼在支持的小景中由共享生活／工作协调器唯一调度；关闭小景、自定义角色或小视口使用 `web/npc-life.js` 回退，两者不并行拥有身体。`roam=true` 是自动活动与邀请的总许可；减少动态、用户休息、隐藏、锁屏和休眠优先。热切沿完整 DesktopOptions／ready／configure 同步，不重建角色 frame、阅读、输入或在途请求。

`dailyRhythm` 已从 schema、设置页及 DesktopOptions 中删除。旧配置的该字段被忽略，不迁移成活动或邀请许可；既有 `companionship` 与 `roam` 保持原值。原先 off 模式下的随机漫游／时段动作停止，需要选择 quiet 或 interactive 才能启用 NPC。默认仍为 off。`web/companionship.js` 只负责显式一起活动和邀请，不再维护自动片段的权重、精力、兴致或截止时间；NPC 独自管理日常意图与情绪。

持久字段 `npcHome` 默认 0.85，范围 0.05–0.95；`npcRange` 默认 0.30，范围 0.10–0.60，步长均 0.01。两者相对当前显示器 workArea 的横向比例，不保存显示器 ID 或全局坐标。Settings 以百分比提供编辑。当前默认产品与简单日常的锚点均在工作区底部，活动区从小窝朝屏幕内侧展开；依据当前真实身体左右边界、尺寸安全余量及可用宽度夹取，不缩小整个原生窗口。过窄工作区停止移动；用户把角色拖出当前活动段后也停止自动移动，需拖回或调整小窝／范围，不横穿段外空间。简单日常的浅蓝色椭圆标记表示小窝，点击穿透；默认自主生活不显示常驻家具；拖动角色不迁移小窝，按住、拖动、空中及松手全过程均保留小窝锚点；安全边距沿用最近落地身体的脚部锚点与矩形，不把拖动时分离的锚点和绘制矩形相减。换角色清除此测量，工作区、尺寸及小窝设置仍正常重新计算。改位置使用小窝百分比设置。当前拖放仍会重力下落，拖动不设置二维停靠位置；默认目标与朝向的已知缺口见[空间与身体复核](design/space-body-review.md)。

感知仅包含位置、鼠标、粗粒度键盘活动、本地时间、DSH 工作事实和显式互动。键盘辅助进程每 500ms 仅输出 active／idle／unknown，最近 1.5 秒有键盘事件为 active；超过 2.5 秒未更新为 unknown，启动超过 15 秒未响应停止该进程。未知时保留目标、安静停留，不能用鼠标或综合空闲替代。它不能区分打字、快捷键和持续按键；不解析按键码、组合键、文本、设备身份、屏幕或其他应用内容，不保存逐键事件和输入序列，不申请额外系统权限。

| 平台 | 适配路径 | 降级边界 |
|---|---|---|
| macOS | 系统 osascript／CoreGraphics [聚合事件时间接口](https://developer.apple.com/documentation/coregraphics/cgeventsource/secondssincelasteventtype(_:eventtype:))，查询当前登录会话 keyDown／keyUp 两类事件的最近时间 | 不安装 event tap；监听授权与聚合时间查询是不同能力，不以前者作前置门槛。负数、非有限值、无历史哨兵或 API 异常为 unknown；物理键盘能力按设备与场景单独验收 |
| Windows | 系统 Windows PowerShell 以 STA 加载包内 C#，注册仅键盘的 [Raw Input](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input) 到不可见消息窗口；仅 WM_INPUT 更新聚合活动时间 | 不调用 GetRawInputData，不拦截／抑制系统输入。注册失败、非交互／远程会话、安全桌面不可读为 unknown；不更改执行策略。原生控制台、物理设备、远程／生命周期和资源按场景分别验收 |
| Linux X11 | `/usr/bin/python3` 标准库 ctypes 加载 libX11／libXi，订阅 [XInput2](https://www.x.org/releases/X11R7.7/doc/inputproto/XI2proto.txt) 的 RawKeyPress／RawKeyRelease 类别；不取 cookie 内容 | 需要 Python 3 与 X11／XI2 库和当前 DISPLAY（XI2 至少 2.1，以覆盖其他应用抓取期间的事件）；不打开 evdev、不要求 root、不读取键位图。原生 Xorg、物理设备、Wayland／生命周期和资源按场景分别验收 |
| Wayland／Xwayland、无 DISPLAY 或普通浏览器预览 | unknown | 不绕过 compositor 的全局输入隔离，不启用宽权限 portal 或综合空闲替代 |

Windows／X11 注册完成后至少观察 1.5 秒才允许 idle。所有辅助进程随父进程退出；禁用陪伴、隐藏或休眠时停止。失败不在轮询中反复重启，可关闭后重新开启陪伴或隐藏后再显示重试。诊断仅增加固定 backend／status 枚举；权限拒绝不能仅凭 unknown 推断。各平台自动协议／策略检查与实物输入验收分别报告。

辅助进程只在原生窗口可见、未挂起且新模式启用时运行，关闭／隐藏／挂起／退出时停止；不持久保存输入历史。诊断开关独立，不启用自动活动。配置组合见[使用指南](usage.md#自主陪伴)。

## 默认桌面生活

生活感分支提供 `livingSpace`（默认 true）与 `npcPersonality: quiet | lively`（默认 quiet），均可在设置或右键菜单热切；陪伴总开关仍默认 off。默认撤下常驻小屋与花箱；贝壳、桌面活动边界和停靠点构成明确目标。整理后外出观察、返回停靠并清醒休息，键盘／鼠标和工作影响同一条循环。对象关注、真实拿放、工作和显式互动的安全交接、原目标续接由同一协调器完成。近期已确认的 pet/play 类别影响关注偏好与整理前等待；自动观察和整理不写相处记忆或关系分数。支持范围与生命周期见[装配契约](design/living-integration-contract.md)。

## 简单日常回退与动作拥有权

纯策略 `web/npc-life.js` 显式接收单调时间、几何、能力、占用与有限输入枚举；保留目标、返回意图、最近三个地点、精力／兴致与情绪。仅运行期保留，重载／换角色重新建立日常，不补算离线探索或成长。

日常为 home → prepare → outbound → observe → prepare → return → home。初始化等待原生 workArea 回执与视口尺寸一致，并在可用且未被用户接管时安置小窝；小窝约停留 7 秒，准备 1.8 秒，实际抵达兴趣点后观察 6.5 秒，回家后可短坐并停留 10 秒。兴趣点从范围内三个位置按距离和近期访问选择。抵达略消耗精力／兴致，回家与停留缓慢恢复；探访后用可用的开心／困倦表情，返回恢复平静。坐标改变或目标失效重新校准；白天允许慢走，夜间及无移动能力角色退化为原地有限观察。只发送 manifest 与 body.words 交集内的词，缺 look／sit 不强发；无 walk 能力或无回执时仍能安静停留。

本分支的共享 kit 已择取上游清醒坐姿修正：日常显式发出的 `sit` 不自行转入睡眠；显式 `sleep` 与用户休息保持原语义。鲸鱼行走摆臂修正只调整渲染参数的合成顺序，不增加 NPC 活动或另一套调度，也不修改邀请、关系计分与任务脸优先级。

移动使用非零、身体代际与递增序号组合的 walkId，仅 stopWalk 自己的 ID。按距离给出 20–60 秒上限，超时未收到匹配到达或身体实际位置不符，不按时间假定抵达；无回执超时后停止该移动，并在当前几何下关闭后续移动。旧身体和旧移动的 arrived／interrupted 不推进新意图。关闭自动活动或退出新模式时释放自己发起的持续坐姿，用户休息与物理占用除外。旧随机漫游入口、`dailyRhythm` 时段策略和早期自动片段调度已移除；一起活动、邀请和关系存档继续复用既有流程。空中、拖拽等物理状态仍由角色引擎／用户拥有。

鼠标靠近角色或前方路径先停，不选逃跑目的地、不追逐。输入 active／unknown 停止探索和自动邀请；目标与情绪保留。角色始终使用用户设置的尺寸，输入、悬停、选中、拖动、面板及状态未知均不触发自动缩放；只有显式修改角色尺寸或预览区域才更新对应 bounds 比例。稳定 idle 后仍按 NPC 的十二秒退让恢复规则重新评估安排，不补播动作。

用户拖动是在新位置放下角色，使用 API 2 的无抛掷 drop，不把拖动速度转成松手惯性或边缘反弹；取消拖动同样在最后有效指针位置放下。开始实际拖动即释放 NPC 自己的移动、取消旧目标和首次自动归位，保留代际／序号以拒绝旧到达回执。放下后先安静等待，区域内从当前位置重新安排，区域外继续停留；不瞬移回小窝，不立即恢复拖动前的旧路线。普通点击、输入和鼠标靠近仍只暂停，不作为重新定位。原生切屏继续由现有几何协议处理；坐姿与摆臂补丁不改变该拖放物理语义。

新 DSH 会话状态变化／新待办／提醒给予至少 12 秒关注；持续活跃任务持续占用。已呈现的长期待办保留入口和任务神态，可允许小窝附近每 15 秒一次有限观察，但不继续外出；既有待办本身不会反复成为“新事件”。草稿、阅读、焦点、选区、在途发送、用户手势、休息和生命周期仍完全优先。占用解除、时钟回退或超过十秒调度缺口重新评估并等待，不补播事件。

NPC 情绪与 Host 任务表情分别保留，任务表达优先。自主动作音按调度拥有权静默，显式互动和工作提示仍沿原音效偏好，不修改全局音效开关。角色运行时按[固定来源与明确补丁](../web/upstream/UPSTREAM.md)维护，不引入模型、道具或等级。

新循环自身不计关系成长；邀请和手动一起活动继续由原纯策略与存档授权，输入未知／活跃时不自动邀请。完全静候时仍至多 30fps 绘制，真实 dt 与工作／输入的原频率保持既有契约。

## 邀请

白天连续可用三十分钟后首次候选，随后等待 30–60 分钟；全 profile 每本地日期最多两次。自主活动不重置可用时间，外部占用会重置。缺少完整一起活动词表的角色不进入邀请候选；显示前持久预留预算；无存档写权限或写入失败则不邀请。邀请有独立视图，不进入任务 broker、收件箱或结果集合，不抢焦点、不发系统通知／模型请求。

仅一个“陪我活动一下”邀请，十秒无回应自然结束。“一起”启动显式活动，“稍后”至少六十分钟冷却，“今天安静”持续到下一本地日期且跨重启保留，可手动恢复。日期回退、重启、换角色不重置预算；时间向前跨日期只允许新日期预算，回退仍使用已观察的日期水位。夜间、隐藏或休眠不邀请、不排队补发。主动打开任何工作或阅读入口取消邀请。

## 有效互动与关系

有效互动有两类：

- 可信主页面确认的抚摸 `pet`：真实指针在角色命中区内连续移动累计超过 320px，指数衰减 1.5/秒，2.5 秒手势冷却；进入命中区的跳跃距离、按下／拖动不计。角色包声称的 touch 只保留原视觉反馈。
- 明确参与的一起活动：从菜单／邀请发起，角色先招手（缺 wave 时用已有开心动作），等待点击或键盘激活“回应她”，再执行有限开心／舞动或点头并完整结束。等待最多 20 秒；没有回应、稍后、Escape、工作／阅读／拖动／关闭陪伴等中断不计完成；重复回应不重启或延长活动。缺少完整词表安全降级。

戳碰、拖拽、自动动作、预览、任务庆祝和无真实输入的包事件不计成长。两类共用五分钟成长冷却、每天最多三次；一次发起与完成共用唯一身份，仅结算一次。关系按角色 id 隔离，换配色／同 id 更新保持。至少三个不同本地日期累计六次有效互动，永久解锁熟悉招呼 `wave → love`，缺词回退；缺席／拒绝不扣关系，不补离线成长。

## 轮流招呼与保存反馈

抚摸与完成活动可以即时表达开心；是否保存、什么时候能声称“记住了”、后续怎样引用、如何纠正／删除与防止旧回执复活，统一由[记忆契约](design/companion-memory-contract.md)定义。反馈在悬停和自身开心反应期间保留三秒，任务／阅读／输入等可提前收起。角色短便笺遵守[近身提示](design/message-visual-system.md#近身互动提示)，不占用工作收件箱或自动抢焦点。

默认产品已接通[5C 回应队列](design/response-rhythm-contract.md)：抚摸保留当场反应，短片段有限合批，稍后表达需当前输入／工作许可与有效保存事实；候选过期或撤销不补播。一起活动的明确回应和单次保存回执仍独立优先。

## 存档与权限

原生 main 持有专用存档；浏览器预览使用同接口的本地服务。均放在各自数据目录，不写入角色内容寻址目录。有限接口为读取摘要、预留邀请、提交互动、稍后／安静／恢复，以及删除角色关系。主 frame IPC 和同源 HTTP 写入各自验证来源、输入大小、角色 id、期望修订和互动身份；角色 iframe 无权限。日期、预算和成长冷却由存档所有者的时钟校验，不接收 Renderer 的日期／分数。

schema 2 保留原 schema 1 的修订、日期水位、全局邀请计数／安静／稍后期限、每角色总互动／最近成长时间／最多三天的计数日期／解锁，以及最多 128 个已结算身份，并增加有界相处记忆与撤销代次。记忆准入、查看／纠正／删除、迁移、容量和招呼变化见[5B 记忆契约](design/companion-memory-contract.md)。旧存档不凭分数生成经历，删除记忆不倒扣关系；最近记得一起活动时可在挥手后增加点头，已解锁的爱心仍保留。同目录使用单写锁；其他实例仍可读取摘要和执行原任务功能，但不邀请或写成长。写入串行、临时文件原子替换、修订冲突拒绝覆盖。锁使用持有进程与唯一 token，退出释放；已确认原持有进程不存在才回收。损坏／未来 schema 保留原字节并进入只读降级，不覆盖；首次缺档才创建。

Renderer 重载仅恢复关系摘要，不恢复活动／邀请／输入。异步读写绑定当前角色与本地代次，迟到回执不能给新角色记分或重显邀请。删除导入角色时删除其关系记录，失败返回明确诊断；全局预算保持。错误诊断有界且不进入聊天正文。

## 验证

策略使用可控时钟／随机源，存档使用临时目录／可控所有者时钟；检查缺词、输入退让与固定尺寸、取消、夜间、预算、幂等、回退时钟、修订、多实例、重启、损坏与未来 schema。浏览器用真实 API 2 body 验证 NPC 出发／抵达／观察／返回、手动互动、邀请和工作／阅读退让。包括 `test:inbox-ui` 的现有全文、草稿、焦点／选区、请求身份和气泡原时钟回归。原生与宿主安装矩阵分别检查设置持久化、IPC、关系恢复和主进程权限。

资源观察按[诊断契约](diagnostics-contract.md)执行。三平台 CI、物理设备、两小时资源观察与日常体验分别结算。

策略在 Renderer 的事件回调与动画帧中统一读取当前单调时钟；不将较早的帧时间戳当作新的策略时刻，以免误判时间回退、取消刚开始的手动活动或 NPC 安排。物理绘制仍使用帧间隔，策略时钟不改变运动速度。

显式“一起活动”按真实会话状态与输入／阅读等占用准入；触摸产生的短暂表情不是工作占用，不应吞掉点击或中断已启动活动。真实工作、审批、输入、阅读和系统挂起仍会立即让出，未完成活动不增长进度。
