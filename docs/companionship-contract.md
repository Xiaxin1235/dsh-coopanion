# 本地自主陪伴契约（P1）

状态：2026-10-15 代码与本机技术验证完成，完整阶段验收仍待远端／物理设备／长期检查；交付与验证进度见 [P1 记录](evidence/p1/README.md)。支持的 Host 版本沿 `package.json` 与 CI 矩阵。独立运行、在线模型闲聊与新图片制作不属于 P1。

## 配置与运行

新增持久枚举 `companionship: off | quiet | interactive`，默认 `off`。`off` 完整保留旧 `dailyRhythm`／calm 路径；`quiet` 使用本地日常和显式互动；`interactive` 额外允许低频邀请。新模式独占闲时调度。设置沿 Host schema、Settings、完整 DesktopOptions、ready baseline、configure 热同步；热切不重建角色、阅读或输入 DOM。通知、音效、陪伴独立配置。`roam=false` 及减少动态效果禁用自主行为和邀请，用户仍可从菜单主动互动；减少动态效果只保留文字反馈；切换时取消当时未完成的活动且不计成长。

没有会话也能陪伴，DSH 无需处于前台。宿主退出或插件停用仍退出桌宠。活跃任务、异常、待办、阅读／回复／通知／菜单／角色面板、草稿与在途发送、悬停入口、用户手势、隐藏、锁屏、休眠都使自动路径退让。一起活动关闭其发起菜单后才开始；用户休息不被自动唤醒。

## 日常决策与动作拥有权

纯策略显式接收单调毫秒、本地小时、有效词表、占用和熟悉度；状态及输出不可变。07:00–22:00 白天等待 45–90 秒，夜间 120–240 秒；解除占用、切时段、时钟回退或超过十秒调度缺口重新等待，不追赶活动。时间只累计可用运行时间。

瞬时精力／兴致范围 0–1，初值 0.6／0.5；每可用分钟精力减少 0.01、兴致减少 0.04。观察权重为 `0.4 + 兴致`，自娱为 `0.2 + 精力 × (1 − 兴致) × 3`，休息为 `0.2 + (1 − 精力) × 3`，等待为 0.15；排除缺词及上一片段后加权选择。自娱完成消耗 0.15 精力、增加 0.35 兴致；休息完成恢复 0.25 精力。均夹在 0–1，不离线衰减，重启恢复中性值。

三类片段：观察 `look → nod → neutral`，自娱 `happy → dance → neutral`，休息 `sit → sleepy → stand → neutral`。词表不足时选择该类安全替代：观察 `nod`，自娱 `happy → nod`，休息 `sit → stand`；每类必须具备复位词，无法成立则跳过。夜间只有观察／休息；不连续重复同一片段。所有片段最多二十秒；时间到但身体仍 `moving` 时等待其实际结束（`busy` 仅代表空中／拖拽等物理占用），超过片段上限取消并不计成长。P1 不主动调用跳跃和自由移动，避免不可取消的空中过程；现有用户物理互动不变。

策略跟踪自己发起的动作，不能将自己的 busy 状态视为外部打断。结束／取消只释放自己的动作；旧角色／旧活动回调不推进新活动。中断后 500ms 内撤去邀请并停止新步骤；已发出的 kit 短手势自然收尾不超过 3.5 秒，坐姿／观察／舞蹈在 body 可接受 `stand` 后复位。空中或用户拖拽不强制复位；任务神态在物理可用后重新应用。原 `neutral` 不是通用取消指令。

P1 完全静候（没有动作、工作、阅读、输入、悬停和在途发送）时至多以 30fps 绘制角色；使用累积的真实 dt，不减慢物理时钟。任一占用或动作恢复原有绘制频率，旧模式完全不变。

## 邀请

白天连续可用三十分钟后首次候选，随后等待 30–60 分钟；全 profile 每本地日期最多两次。自主活动不重置可用时间，外部占用会重置。缺少完整一起活动词表的角色不进入邀请候选；显示前持久预留预算；无存档写权限或写入失败则不邀请。邀请有独立视图，不进入任务 broker、收件箱或结果集合，不抢焦点、不发系统通知／模型请求。

仅一个“陪我活动一下”邀请，十秒无回应自然结束。“一起”启动显式活动，“稍后”至少六十分钟冷却，“今天安静”持续到下一本地日期且跨重启保留，可手动恢复。日期回退、重启、换角色不重置预算；时间向前跨日期只允许新日期预算，回退仍使用已观察的日期水位。夜间、隐藏或休眠不邀请、不排队补发。主动打开任何工作或阅读入口取消邀请。

## 有效互动与关系

两类：可信主页面确认的抚摸 `pet`（真实指针在角色命中区内连续移动累计超过 320px，指数衰减 1.5/秒、2.5 秒手势冷却；进入命中区的跳跃距离不计，按下／拖动不计；角色包声称的 touch 仅保留原视觉反馈），和用户从菜单／邀请显式发起并完成的一起活动。戳碰、拖拽、自动动作、角色预览、任务庆祝和无真实输入的包事件不计成长。连续抚摸合并；两类共用五分钟成长冷却、每天最多三次。抚摸反馈在悬停和自身开心反应期间保留三秒，任务／阅读／输入仍可提前收起。一次发起与完成共用不可重用身份，仅结算一次；被打断的活动不计。

关系按角色 id 保存，换配色和同 id 更新保持，换角色隔离；全 profile 的邀请预算和安静日期共享。至少三个不同本地日期累计六次有效互动解锁熟悉招呼：`wave → love`，缺词回退普通招呼，并在可访问状态中说明。解锁永久且幂等，缺席／拒绝不扣分。只有存档确认后显示关系进展／解锁。P1 不提供等级刷取、离线收益或饥饿惩罚。

## 存档与权限

原生 main 持有专用存档；浏览器预览使用同接口的本地服务。均放在各自数据目录，不写入角色内容寻址目录。有限接口为读取摘要、预留邀请、提交互动、稍后／安静／恢复，以及删除角色关系。主 frame IPC 和同源 HTTP 写入各自验证来源、输入大小、角色 id、期望修订和互动身份；角色 iframe 无权限。日期、预算和成长冷却由存档所有者的时钟校验，不接收 Renderer 的日期／分数。

schema 1 包含修订、日期水位、全局邀请计数／安静／稍后期限、每角色总互动／最近成长时间／最多三天的计数日期／解锁，以及最多 128 个已结算身份。同目录使用单写锁；其他实例仍可读取摘要和执行原任务功能，但不邀请或写成长。写入串行、临时文件原子替换、修订冲突拒绝覆盖。锁使用持有进程与唯一 token，退出释放；已确认原持有进程不存在才回收。损坏／未来 schema 保留原字节并进入只读降级，不覆盖；首次缺档才创建。

Renderer 重载仅恢复关系摘要，不恢复活动／邀请／输入。异步读写绑定当前角色与本地代次，迟到回执不能给新角色记分或重显邀请。删除导入角色时删除其关系记录，失败返回明确诊断；全局预算保持。错误诊断有界且不进入聊天正文。

## 验证

策略使用可控时钟／随机源，存档使用临时目录／可控所有者时钟；检查缺词、权重、取消、夜间、预算、幂等、回退时钟、修订、多实例、重启、损坏与未来 schema。浏览器用真实 API 2 body 验证三类片段、手动互动、邀请和工作／阅读退让。包括 `test:inbox-ui` 的现有全文、草稿、焦点／选区、请求身份和气泡原时钟回归。原生与正式两版 Host 安装分别检查设置持久化、IPC、关系恢复和主进程权限。
