## 当前授权与交付

2026-10-21 用户指出默认体验机械、偏响应式，授权关闭体验进程并打通已完成阶段。本轮已把二维空间、连续物件动作、生活／工作协调、人格关注、有限相处记忆和回应节奏接入默认内置鲸鱼。可观察闭环为：关注对象 → 实际接近和整理贝壳 → 被工作或显式互动安全打断 → 核对原对象和目标后继续 → 观察与清醒休息。已归位的贝壳在本次运行不重复搬动。

本轮实现、完整本机验证与说明已完成，并作本地提交；最终身份及固定结果见[装配报告](reports/living-integration-20261021.md)，最终行为见[装配契约](design/living-integration-contract.md)。本轮未扩展第 6／7 期、模型心跳、自由画像、出门或自主跨屏；未推送、合并、安装日用 Host 或发布。

## 验证与限制

最终测试数量、工具链、逐文件摘要和本地包按[固定报告](reports/living-integration-20261021.md)及其验证清单核对。浏览器受控键盘／工作事实、真实 Cordis 装配、隔离原生 IPC／系统输入枚举分别记录；不等于真实模型、物理键盘／多屏、三平台 CI、长期资源或日用 Host 安装验收。

本轮修正了释放编排姿态后缺失站立测量、接触时鼠标自动转身抢占朝向、共享身体缺少拖放接口，240px 底部导航边距、关闭小景时误交接和非生活手势误清理；失败复现和修正后结果保留于新证据目录。既有原生重启后命中的旧间歇性超时仍不宣称根因已修复，即使本轮完整检查通过。

当前是有限的本地自主生活策略：一个运行期整理目标与真实对象观察，最多 32 个工作源；容量／来源未知保守暂停。接触失败或目标阻塞不盲目重试；不读取屏幕或其他应用正文，不新增模型调用。
