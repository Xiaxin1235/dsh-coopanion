## 验证边界

动作补丁与栅格修正的完整本地验证已完成：290 项 Vitest 通过（1 原有跳过）、12 项 Node 单元、类型／构建／元数据、完整 `test:ui` 与 `test:inbox-ui`；包含 16 项真实 WebGL、9 项导航、30 项空间、O03 像素及 44 项动作回归。隔离 Electron 的 8 项单屏检查完成，包含恢复后拖动、真实 macOS 光标命中、旧 API 2 回退与帧 URL 防积压。

固定源码摘要、实际宿主、完整结果及修复前后的区别见[动作补丁与原生回归归档](archive/2026-10-aliveness/upstream-motion/README.md)。原始 JSON 与日志已保留到仓库，截图／录像等大体积材料仍在本机；旧“4 项通过、后半段超时”只属于修正前记录。第 2 期验收身份及早期未定位观察见[阶段归档](archive/2026-10-aliveness/stage-2/README.md)。

该结论覆盖 macOS 单屏 DPR 2 的受控原生预览。三平台 CI／安装矩阵以实际工作流为准；物理多屏／混合 DPI、真实 OS 休眠／锁屏、底层应用点击送达、长期资源表现和真实 Harness／模型会话仍需各自验证。此轮未生成分发包、安装或发布。
