# 生活感功能：当前开发状态

生活感分支唯一接手入口；先读[文档索引](README.md)，继续使用 `codex/aliveness-foundation`。版本、依赖、命令以 package、shrinkwrap 与工作流为准；历史下一步不构成当前授权。

## 当前授权与状态

2026-10-22 用户体验 `b372fd0` 后明确指出整理卡顿、重复弯腰空抓、探索缺少完整循环、小屋／珊瑚遮挡，以及互动与环境缺少因果。本轮按此反馈修正，实现／验证和文档同步后本地提交；实现和本机完整回归已完成，已作本地提交；具体身份从验证清单核对。前一版工程通过不算 LIVE 感验收通过。

本轮重点：

- 整理／拿放和注意力对齐按显示帧节奏更新；根位置不动不再等同完全空闲。
- 空手站立暂停后直接安全恢复，不播抓取收手；已完成整理不重复搬动。
- 默认撤下常驻小屋、珊瑚，保留有限桌面活动范围、停靠位置与小贝壳；制作工作台保留原资源。
- 整理后按实际到达和观察进度接上“外出留意活动边界 → 返回停靠 → 清醒休息 → 再次外出”；工作与用户接管保留当前目标。
- 实际键盘 active／idle／unknown、全局鼠标位置、已接通的 Host 工作元数据和生命周期变化影响同一身体。打字／鼠标靠近先安全交接再注视；稳定空闲后续接，系统恢复只产生有限新反馈。

行为与容量以[桌面生活契约](design/living-integration-contract.md)为准；源码身份、测量和固定结果见[反馈修正报告](reports/desktop-feedback-20261022.md)。本轮未扩模型调用、前台应用／窗口正文感知、自由画像、出门或自主跨屏；未推送、合并、发布或安装日用 Host。

## 验收边界

第 1–3 期原指定地图／180px 主配色／40px O03 的用户确认保持其原范围。第 4–5C 期、默认装配和本轮桌面伴随的自然度仍待用户再次体验，不用计数、进程 ready 或自动化替代。

浏览器使用真实 WebGL／导航／接触／存档，输入与工作事实受控。隔离原生使用真实 IPC、OS 鼠标和系统键盘适配器；有界工作恢复场景显式控制输入枚举，真实枚举观察另存。没有本轮四版本真实模型、物理键盘／多屏、三平台 CI、长期资源或日用安装验收。

之前默认预览不连接 Harness，所以其工作事件仅能模拟；实际插件通过 WorkSources 进入主页面。鼠标与输入是已有粗粒度信号，不读取按键正文、桌面截图、其他应用内容或窗口内容。系统恢复依据可信生命周期；不把帧间缺口猜成特定用户活动。

## 操作与后续

旧体验已关闭并保留 `.cache/living-preview-20261022/` 存档；原 4189 制作页与未导出布局保留，不重启或替换。原生测试使用临时 profile，桌面操作串行，退出后清理自身窗口。

新体验默认打开自主生活和闲时走动；无需常驻家具。选择安静／活泼改变关注和休息间隔；鼠标靠近会让位并留意，离开后重新评估。键盘持续活动时安静守候，停止后需要约 8 秒稳定空闲；unknown 保守停止自主活动。

下一步先让用户体验这一条有环境因果的循环，再按实际观感修正。当前授权不自动产生第 6／7 期、模型或新的系统读取能力。

前一版状态原字节见[装配快照](archive/2026-10-aliveness/desktop-feedback/README.md)。历史阶段、报告与失败按形成时身份解释，不恢复成当前任务。
