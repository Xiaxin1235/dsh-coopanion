# v0.4.12

## DSH 0.2.1 候选版兼容

- 修复旧声明导致新宿主拒绝加载：声明支持 DSH 0.2.1-rc.1 和 0.2.1-rc.2，保留 0.2.0-rc.2 与 0.2.1-alpha.1；所有宿主 peer 使用精确版本列表，并新增 `engines.dsh` 供新宿主判断兼容性，未验证版本仍不放行。
- 三平台安装矩阵扩为四版宿主、十二组同包安装，继续检查任务完成、冷会话续接、通知、设置、原生窗口、重启恢复及陪伴配置。
- 安装验证适配新宿主从账号菜单进入设置的导航变化，继续验证桌宠设置、中文／英文切换和持久化。
- 安装恢复场景用受控未完成回复验证“接受不等于完成”，等待前一轮真正结束后再建立测试审批，避免慢速环境下测试回合重叠损坏日志。
- 修复 Windows 关闭诊断时发现文件撤销与读取竞争造成的偶发 `EPERM`；有限重读后按实际接口状态处理，持续错误和无效数据仍明确报错。
- 固定戳触回归的随机分支，分别验证短暂表情可互动、跳跃物理占用仍优先、落地可开始及工作可中断，避免将空中拒绝误报为表情阻塞。
- 同步安装指南、开发／发布说明及独立观察工具支持列表。自主陪伴仍是默认关闭的 P1 试用功能；物理设备和长时体验验收范围不变。

安装包：`dsh-coopanion-0.4.12.tgz`；npm 与 GitHub Release 的版本化包、固定别名使用同一份发布 CI 验证的压缩包。
