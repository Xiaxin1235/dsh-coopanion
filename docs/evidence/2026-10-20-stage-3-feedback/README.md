# 第 3 期花箱与拾取反馈：固定回归

这批记录对应 2026-10-20 用户两张截图，修复基线为首轮第 3 期提交 `2c3971b`。当前行为从[开发入口](../../aliveness-development.md)和[连续动作契约](../../design/continuous-action-contract.md)核对，固定 JSON 不授权后续实施或发布。

## 反馈与最小根因

- 下方花箱 `(580,528)`：原模型报告 `disconnected-in-rectangle-model`。最小复现只需花箱和岗位的立面，它们被完整身体扩张后错误连接成墙；任意去掉其中一个障碍，错误封路消失。
- 移开花箱至 `(558,252)`：能真实到岗，但拾取收到 `navigation-interrupted / target-blocked`。最小复现只需小窝立面和贝壳接近站位；换拾取朝向仍失败，恢复标定地面规则则两侧均可达。导航身份没有错配。

`before.json` 保存修复前真实浏览器失败，两个反馈检查都为 false。修复使动作与手动行走共用已标定地面模型，保留完整宽度的有限地面扫掠及完整内容禁区／世界边界／未知实体避让；真实触物与拥有权门槛未放宽。动作执行器还保留具体拒绝原因，避免将不可达笼统显示为 interrupted。

## 夹具与边界

花箱坐标与第一张图的角色 `(112,640)` 来自截图界面。北柱 y=18 按显示的 564px 间隙推算，贝壳约按 x=335/y=450 重建；这是可复现的截图近似，不是用户导出的布局。单元另外覆盖相邻贝壳纵深。原截图原字节保留在本机 `artifacts/stage-3-feedback-inputs/`，摘要在综合记录中。

`browser.json`、`native.json` 保存相同源码摘要及实际运行时，验证原位花箱实际到岗、移开后返回拾取、持物更换落点和放下，以及连续采样路径的碰撞规则。原生仅为临时 profile 的受控单屏窗口，未执行真实 OS 休眠／锁屏或其他应用操作。

大体积截图／页面录像留在各 `artifacts/stage-3-feedback-*` 本机目录。原始 JSON 与日志保持字节不变；`SHA256SUMS` 对应实际保存的文件，提交后另外逐项验证 Git blob 与记录源码摘要。未生成分发包、安装、推送、合并或发布。
