# 未计入验收的尝试

这些文件保留采集的原字节，不能据此判定仅鼠标感知失败或正式通过。

- `physical-initial.json`：agent 准备阶段的未通知基线；没有正式人工输入流程。
- `physical-confirmed.json`：聊天提示分阶段，检测到真实输入退让；用户确认停键较晚／期间仍有按键，且随后要求重做。第二段 active 不属于可控的仅鼠标证据。
- `physical-mouse-package.json`：固定新包，用户反馈“我没看到你的要求，重来”。鼠标段 active 的实验条件未成立；raw 文件内的布尔结果只描述数据，不能作为正式结论。

后续改用可见开始按钮与倒计时面板，不用聊天提示到达时间定义人工阶段。

- `physical-panel-timeout.log`：首个非聚焦面板 180 秒未收到开始信号，未执行人工阶段，自动关闭；不代表产品输入感知失败。之后改用当前鼠标屏幕上的可聚焦面板和临时输入框。
