# v0.4.8

## 桌宠语言跟随 Harness

- 启动时读取 Harness 已保存的中英文偏好；Client 独立订阅实际解析的语言与回退链，切换立即同步，关闭通知或尚未挂载 workspace 时也能更新。
- 移除通知轮询对语言的覆盖；当前 Harness 窗口获得焦点时重新同步，断线后重试，快速切换会撤销旧请求。清除显式偏好后恢复自动语言。
- 桌面菜单、聊天、会话列表、收件箱、完整阅读、角色面板、动作／配色选项、日期、提示和无障碍文案共用中英文解析规则；原生托盘状态、提示和菜单同步切换。
- 已打开的面板更新语言时，保留当前角色与配色、阅读正文、用户输入、会话标题和 AI 回复。应用自身的提示使用当前语言，原始会话内容保持原文。

新增语言同步、超时与重试、快速切换、整套英文界面、热切换、自动语言恢复及原生 JSON IPC 回归；实际 Harness 安装检查覆盖设置切换后桌宠立即更新。

安装包：`dsh-coopanion-0.4.8.tgz`。npm、版本化 Release 包及固定别名 `dsh-coopanion.tgz` 使用同一份通过 CI 的压缩包。
