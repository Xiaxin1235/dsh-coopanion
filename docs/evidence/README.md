# 历史原始证据

本目录保留固定运行产生的 JSON／NDJSON 报告、日志、截图、录像、摘要及发布附件，供问题复现、产物核验和许可追溯。具有追溯价值的过程说明集中在[历史说明](../archive/README.md)，固定版本的综合结果见[观察报告](../reports/README.md)；更早且已删除的重复交接说明从 Git 历史查询。

这些文件不随 npm／Release 安装包分发，也不作为当前任务、配置或验收状态。当前行为从 [文档索引](../README.md) 进入；已发布产物的身份从对应 GitHub Release 的 `verification.json` 与 `SHA256SUMS` 核对。

追溯时使用 `rg --no-ignore docs/evidence`。先核对报告内的提交、包摘要、宿主、平台、控制条件与时间范围；不同包或受控测试的结果各自解释。本机绝对路径只标识当时环境，失败日志和缺口保持其原始含义。保留的 Markdown 发布附件和原始报告也是历史快照，不是接手指令。
