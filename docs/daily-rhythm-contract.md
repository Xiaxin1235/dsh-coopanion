# 日常陪伴节奏契约（M6）

产品保持 v0.4.8，支持 DSH 0.2.0-rc.2 / 0.2.1-alpha.1。基线为 M5 本地验收 `60a7f2e648345fb624d502d88c365ead0b7100e3`，其最终实现为 `a392084f81d62b5ddcadb8c43836e453922f21a2`。按用户明确要求继续独立可验证的 M6；M3 三平台退出条件、M5 物理多屏/混合 DPI、维护者审阅和远端 CI 仍待验收。

## 目标与配置

已有 calm 漫游在持续空闲时自行选择动作，不能表达夜间更安静、活动间隔更长的偏好。本项提供可选的本地时段策略，减少夜间活动，工作和阅读始终优先。它没有模型请求、前台内容采集、额外通知或新素材。

持久字段 `dailyRhythm: boolean` 默认 `false`，旧配置保持原有 calm 行为。缺失/空值遵循既有 Harness schema 的默认行为，其他非布尔值拒绝保存。Harness **Settings → 桌宠 → 日常陪伴节奏** 保存至现有 volatile 配置，经完整 `DesktopOptions` → `PetControls.configure` → `ElectronBridge` → 原生 main → 当前 Renderer 热同步；原生及完整 Host 重启使用同一持久值。`roam=false`、用户休息和系统减少动态效果设置始终禁用闲时策略。

启动握手期间收到的新 configure 同时更新桥接层完整配置缓存，ready 的 baseline 使用最新配置，避免旧启动参数盖回新偏好；locale 清空仍显式传 null。generation、原生显示回执、最新 Host 全文快照及通知资格判断保持原协议。

本地时间取运行 Renderer 的系统本地小时，不使用聊天的 `clientTimeZone` 或 Harness 语言推断。白天为 07:00（含）至 22:00（不含），夜间为 22:00 至次日 07:00。首次启用、解除占用、跨时段、单调时钟回退或超过 10 秒的调度中断后重新等待完整间隔；不会补播错过的活动。日期、时区或系统时钟改变后，以当前本地小时重新计算时段，等待使用单调时钟。

## 策略与角色

共享纯策略位于 `web/daily-rhythm.js`，输入显式携带单调毫秒、本地小时、随机源、有效词表和占用状态。白天每 45–90 秒尝试 `look`、`nod`、`wave` 或 `sit`；夜间每 120–240 秒仅尝试 `nod` 或 `sit`。均匀选择可用且不同于上一动作的词，间隔独立均匀取样。`look` 最多 4 秒、`nod` 1 秒、`wave` 2 秒；`sit` 白天 8 秒、夜间 15 秒。只选择角色 manifest 与实际 `body.words` 的交集，动作需要 `neutral` 复位，`sit` 还需要 `stand`；缺失或去重后无候选时保持待机，不能假造能力。

默认关闭时仍使用已有 calm 调度和上游去重；开启后仅在该可选闲时路径中将自由 roam 设为 off，经已有 API 2 `do` 发出上述有限动作。原物理/角色引擎、拖动、抛掷与其他用户手势保持原实现。动作结束释放自有动作，坐下先 `stand`，再清除临时表情并恢复当前 Host 神态；不建立另一套角色状态机。

任务（含后台工作、成功庆祝和异常）、待办、阅读/回复/通知/菜单/角色面板、输入及在途发送、拖拽/按下/物理动作、悬停入口、用户休息、减少动态效果、隐藏或休眠均让闲时策略退让。占用取消当前自有活动，释放后重新等待；不能覆盖任务表情或唤醒用户选择的休息。来自用户的新手势不由策略复位覆盖。每次更换角色重置策略身份，不向新角色重放旧动作。

热切换该偏好只更新策略与 controls，不调用内容 render；保留角色 frame、捕获阅读 DOM/正文和滚动像素偏移、草稿、焦点/选择、在途身份及气泡原时钟，不产生 read/select/chat。M1–M5 的既有契约继续生效；崩溃后的临时状态丢失边界不变。

## 资源与验收

先在固定 M5 干净源码/产物和本机 macOS arm64 / Electron 44.7.0 上测量原生可见待机，再在同一环境比较 M6 关闭、白天与夜间开启。入口 `scripts/measure-idle.mjs`：隔离 profile、内置角色 180px、roam=true、20 秒预热，每组至少三段 60 秒，记录 Electron 主进程和所有子进程的累计 CPU 差分（100% 为单核）及 RSS。开/关对照仅注入本地小时，动画与物理按真实时间推进。采样器自身不计入角色进程树，RSS 总和可能重复计算共享页。

预算在基线完成后、产品实现前记录于 [M6 记录](evidence/m6/README.md)。有界观察与可控浏览器检查不等同于长期真实待机验收；远端三平台和两版 Host 六组矩阵沿用，其他平台与真实长期使用仍独立标记。
